## 1과목
#### 데이터의 특성
- <strong><mark style="background:#fff88f">존재적 특성 : 객관적인 사실 그 자체(Fact)</mark></strong>
- <strong><mark style="background:#fff88f">당위적 특성 : 추론·예측·전망·추정의 근거(Basis)</mark></strong>
- 데이터는 현실을 그대로 반영하는 ‘**존재적 특성**’과 맥락 속 의미부여 가능한 ‘**당위적 특성**’을 가짐

#### <mark style="background:#fff88f"><font color="#ff0000">DIKW 피라미드</font></mark>
- DIKW는 데이터(Data), 정보(Information), 지식(Knowledge), 지혜(Wisdom) 순으로 가치가 높아지며, 각 단계는 앞 단계를 가공·연결·내면화한 결과이다.
 ![282](/assets/images/Pasted%20image%2020261030184139.png)
- <mark style="background:#fff88f">데이터(Data)</mark>
	- <mark style="background:#fff88f">가공 전의 객관적인 사실</mark>
	- 예) A대리점 휴대폰 100만원, B 대리점 휴대폰 200만원
- <mark style="background:#fff88f">정보(Information)</mark>
	- <font color="#ff0000">데이터를 가공·처리</font>해 데이터 간의 <font color="#ff0000">관계(패턴)와 의미</font>를 도출
	- 예) A 대리점의 핸드폰 가격이 저렴하다
- <mark style="background:#fff88f">지식(Knowledge) </mark>
	- 정보의 패턴을 통해 <font color="#ff0000">예측·의사결정에 활용</font>
	- 지식은 <strong>정보를 구조화</strong>해 얻은 <font color="#ff0000">규칙·패턴을 내재화</font>
	- 예) 휴대폰을 구매할 때 A 대리점을 이용하는 것이 유리하다
- <mark style="background:#fff88f">지혜(Wisdom)</mark>
	- 축적된 <font color="#ff0000">지식과 창의적 사고를 결합</font>하여 판단
	- 지식을 바탕으로 한 창의적 판단과 적용 능력
	- 예) A 대리점의 다른 기기도 저렴할 가능성이 있다고 판단

#### 데이터의 유형
##### <mark style="background:#fff88f">1. 형태에 따른 분류</mark>
- <strong>정형데이터</strong>
	- 정해진 구조와 형식에 따라 저장된 데이터
	- 관계형 데이터베이스(RDB), 엑셀 스프리드시트, CSV
- <mark style="background:#fff88f"><strong><font color="#ff0000">반정형데이터</font></strong></mark>
	- 데이터를 설명하는 <mark style="background:#fff88f"><strong><font color="#ff0000">메타데이터를 포함</font></strong></mark>
	- **HTML, XML, JSON**, **RDF**, <font color="#ff0000">로그 데이터</font>
- <mark style="background:#fff88f"><strong><font color="#ff0000">비정형데이터</font></strong></mark>
	- 정해진 구조나 형식 없이 다양한 형태로 존재하는 데이터
	- SNS, 이미지, 음원, 동영상

#### <mark style="background:#fff88f"><strong><font color="#ff0000">암묵지, 형식지간 상호작용</font></strong></mark>
- 노나카의 SECI 모델은 공통화, 표출화, 연결화, 내면화가 순환하면서 조직의 지식이 나선형으로 커진다고 본다.
- **암묵지** : 개인에게 습득되고 겉으로 드러나지 않음
- **형식지** : 문서, 매뉴얼 등의 형상화된 지식

- <mark style="background:#fff88f"><strong><font color="#ff0000">공통화</font></strong></mark> : 암묵지 지식을 다른 사람에게 알려줌(<mark style="background:#fff88f"><strong><font color="#ff0000">암묵지 -> 암묵지</font></strong></mark>)
- <mark style="background:#fff88f"><strong><font color="#ff0000">표출화</font></strong></mark> : **암묵지 지식을** 매뉴얼이나 **문서 등의 형식지로 변환**하는 과정 (<mark style="background:#fff88f"><strong><font color="#ff0000">암묵지 -> 형식지</font></strong></mark>)
- <mark style="background:#fff88f"><strong><font color="#ff0000">연결화</font></strong></mark> : **여러 형식지들을 결합**하여 **새로운 형식지**를 만드는 과정(<mark style="background:#fff88f"><strong><font color="#ff0000">형식지 -> 형식지</font></strong></mark>)
- <mark style="background:#fff88f"><strong><font color="#ff0000">내면화</font></strong></mark> : **형식지를** 학습해 개인의 **암묵지로 체화** (<mark style="background:#fff88f"><strong><font color="#ff0000">형식지 -> 암묵지</font></strong></mark>)
- <font color="#245bdb">'공표연내'</font>

#### 데이터베이스의 특징
##### <mark ><mark style="background:#FFE868"></mark><strong><font color="#ff0000">대표적인 4가지 특징</font></strong></mark>
- **공용 데이터** : 여러 사용자가 공동으로 이용하는 데이터
- **통합된 데이터** : 데이터의 **중복을 최소화**하고 통제하여 관리하는 데이터
- **저장된 데이터** : 저장매체에 저장된 데이터
- **변화되는 데이터** : 새로운 데이터의 삽입, 기존 데이터의 삭제·갱신이 발생하는 데이터 (<strong><mark style="background:#fff88f">무결성</mark></strong>)
- <font color="#245bdb">'공통저변'</font>
- 물리적 위치가 아닌 내용 값으로 데이터를 찾는 <mark style="background:#fff88f"><strong><font color="#ff0000">내용에 의한 참조 </font></strong></mark>

##### 다양한 관점의 가치
- <font color="#ff0000">정보 축적 및 전달 측면</font> : 정보를 저장하고 쉽게 검색·전달 (<font color="#ff0000">기계가독성, 검색가독성, 원격조작성</font>)
- 정보 이용 측면 : 정보 활용 및 새로운 정보 생성
- <font color="#ff0000">정보 관리 측면 : 정보의 체계적 관리와 효율성 향상</font>
- 정보기술 발전 측면 : 데이터 처리 기술과 관련 기술 발전
- 경제·산업 측면 : 생산성 향상 및 새로운 산업 서비스 창출

#### 데이터베이스 설계 절차
1. **요구조건 분석**: 사용자 요구사항 수집 및 분석
2. **개념적 설계**: 요구사항을 바탕으로 개념적 스키마 생성 (ER 모델, ERD)
3. **논리적 설계**: 데이터 모델(관계형, 계층형, 네트워크형)을 선정하고 논리적 스키마 설계
4. **물리적 설계**: 저장 구조, 접근 경로, 인덱스 등 설계

#### DBMS
- 데이터베이스를 생성·관리하고 사용자의 데이터 접근을 지원하는 소프트웨어
- **관계형 DBMS(RDBMS)**
	- 데이터를 테이블 형태로 구성하고 관계를 이용해 관리
	- MySQL, MariaDB, Oracle
- <mark><strong>NoSQL DBMS</strong></mark>
	- 관계형 모델 외의 다양한 데이터 모델을 지원하며, <mark><strong>비정형 데이터 저장 처리 가능.</strong></mark>
	  - **HBase**, MongoDB, **CouchDB**, Redis, **Cassandra**

#### 데이터베이스 스키마 및 관련 용어
- **데이터베이스 스키마**: 데이터베이스의 구조와 제약조건에 관한 명세
- <mark><strong>메타데이터</strong></mark>: 데이터를 설명하는 데이터. 데이터 구조를 설명하고 검색하는데 활용(테이블 구조, 속성, 데이터 타입, 제약조건 등)
- **데이터 사전(Data Dictionary)**: 메타데이터를 저장하는 시스템 내 저장소
- **인스턴스(Instance)**: 특정 시점에 데이터베이스에 실제로 저장된 데이터.
- <mark><strong>인덱스(Index)</strong></mark>: 데이터 검색 속도를 높이기 위한 보조 자료도구.


#### 기업 내부 활용 데이터베이스
- <mark style="background:#fff88f"><strong><font color="#ff0000">OLTP </font></strong></mark>(Online Transaction Processing): 다량의 단기 <font color="#ff0000">거래</font>를 실시간으로 처리 (계좌이체, 상품 주문, 결제)
	- OLTP가 데이터 웨어하우스를 거쳐 OLAP 분석에 활용됨.
- <mark style="background:#fff88f"><strong><font color="#ff0000">OLAP</font></strong></mark> (Online Analytical Processing): <mark style="background:#fff88f"><strong><font color="#ff0000">다차원 데이터</font></strong></mark>를 <font color="#ff0000">대화식으로 분석</font>하여 의사결정 지원 (지역별 매출 분석, 연도별 실적 비교)
	- 다차원 데이터 : 연도, 지역, 제품 등 여러 기준으로 구성된 데이터
	- 대화식 분석 : 분석 조건을 바꿔가며 원하는 결과를 확인하는 방식
- OLTP는 현재 시점의 거래 처리(삽입·수정·삭제) 중심이고, OLAP는 누적된 데이터의 조회·집계 중심
- <mark style="background:#fff88f"><strong><font color="#ff0000">CRM</font></strong></mark> (Customer Relationship Management): <mark style="background:#fff88f"><strong><font color="#ff0000">고객 정보를 분석</font></strong></mark>하여 고객 관리 및 마케팅에 활용
- <mark style="background:#fff88f"><strong><font color="#ff0000">SCM</font></strong></mark> (Supply Chain Management, 공급망 관리): 원자재 조달부터 생산·유통까지 <mark style="background:#fff88f"><strong><font color="#ff0000">공급망을 통합 관리하고 최적화</font></strong></mark>
- <mark style="background:#fff88f"><strong>ERP</strong></mark> (Enterprise Resource Planning, 전사적 자원 관리): <font color="#ff0000">기업의 자원을 통합 관리</font>하여 경영 효율성 향상
- **RTE (Real-Time Enterprise, 실시간 기업)**: 실시간으로 정보를 파악하고 **신속한 의사결정**과 업무 대응 지원
- **BI (Business Intelligence)**: 기업 데이터를 분석·정리하여 **보고서와 대시보드 등 의사결정에 필요한 정보 제공**
- **BA (Business Analytics)**: 통계기반 비즈니스 의사결정 지원.
- **블록체인(Blockchain)**: 네트워크 참여자들이 거래 정보를 분산 저장하고 공유하며, 데이터의 위·변조를 어렵게 하는 기술
- **KMS (Knowledge Management System)**: 기업의 지식을 수집·저장·공유·활용하여 **조직의 지식 자산 관리**

#### <mark style="background:#fff88f">데이터웨어하우스(DataWareHouse, DW)</mark>
- 기업 내외부 다양한 데이터를 한 곳에 저장한 중앙 저장소 
- 구성요소
	- ETL(Extraction, Transform, Load) : 다양한 소스 데이터 추출, 정제, 적재
	- ODS(Operational Data Store) : 다양한 DBMS에서 추출한 데이터를 임시 저장
- <mark style="background:#fff88f"><strong><font color="#ff0000">특징</font></strong></mark>
	- 주제지향성 : 분석목적 설정이 중요
	- 데이터 통합 : 일관화 된 형식으로 저장
	- 시계열성 : 히스토리를 가진 데이터
	- <strong><mark style="background:#fff88f">비휘발성</mark></strong> : 읽기전용 - 수시로 변하지 않음

#### <mark style="background:#fff88f"><font color="#ff0000">데이터 마트(DM)</font></mark>
- 특정 주제에 맞게 데이터를 모아 놓은 <mark style="background:#fff88f"><strong><font color="#ff0000">소규모 데이터 웨어하우스</font></strong></mark>
- <strong>데이터 마트는 데이터 웨어하우스의 일부</strong>로서, 특정 부서나 주제의 사용 목적에 맞게 필요한 데이터를 구성한 저장소
- 원천 데이터 수집 → 데이터 웨어하우스 → 데이터 마트

#### 데이터레이크(DataLake)
- 비정형 데이터를 저장하며 하둡과 연계하여 처리
	※ 하둡 : 여러 컴퓨터를 하나로 묶어 대용량 데이터를 처리하는 오픈 소스 빅데이터 솔루션
- HDFS : 분산형 파일 저장 시스템
- MapReduce : 분산된 데이터를 병렬로 처리

#### 빅데이터 출현 배경
- <mark style="background:#fff88f"><strong><font color="#ff0000">클라우드 컴퓨팅(온디맨드)</font></strong></mark>, <mark style="background:#fff88f"><strong><font color="#ff0000">분산 처리 기술(하둡 기반)</font></strong></mark>, 비정형 데이터 확산, 디지털화, 인터넷 및 모바일 기기 보급, IoT 발달


#### 빅데이터 처리 기반 기술
- **하둡(Hadoop)** : 대용량 데이터를 여러 컴퓨터에 <strong>분산 저장하고 처리</strong>하는 프레임워크
- **HDFS** : 대용량 파일을 여러 컴퓨터에 <strong>분산 저장</strong>하는 분산 파일 시스템
- <mark style="background:#fff88f"><strong><font color="#ff0000">맵리듀스(MapReduce)</font></strong></mark> 
	- 구글이 제안한 분산 처리 모델
	- 대용량 데이터를 <strong>여러 대의 저렴한 범용 서버</strong>에 나누어(Map) <strong>병렬로 처리</strong>한 뒤 결과를 모아(Reduce) 합치는 분산 처리 방식
		- Map : 입력 데이터를 키-값 형태로 분류·변환
		- Reduce : 같은 키를 가진 데이터를 모아 집계·처리
	- 정형뿐 아니라 로그·텍스트 같은 <strong>비정형 데이터도 처리</strong>
	- 대량 데이터를 한꺼번에 처리하는 배치 방식

#### 데이터 단위
- 비트(Bit)는 데이터를 표현하는 가장 작은 단위이며, 0과 1 중 하나의 값을 나타냄
- 1바이트(Byte)는 8개의 비트로 이루어짐
- KB < MB < GB < TB < <mark><strong>PB($2^{50}$) < EB($2^{60}$) < ZB($2^{70}$) < YB($2^{80}$)</strong></mark> (Peta < Exa < Zetta < Yotta)
- '패지요!'


#### <mark style="background:#fff88f">빅데이터의 3V (가트너 정의)</mark>
- <mark style="background:#ffff88"><strong><font color="#ff0000">Volume</font></strong></mark>(규모) : 데이터 양 증가
- <mark style="background:#ffff88"><strong><font color="#ff0000">Variety</font></strong></mark>(다양성) : 데이터 유형 증가
- <mark style="background:#ffff88"><strong><font color="#ff0000">Velocity</font></strong></mark>(속도) : 데이터 생성, 처리 속도 증가
- ※ 그 외 5V/7V에 포함되는 요소
- Value(가치) : 숨겨진 가치 발견이 중요
- Veracity(신뢰성) : 고품질 데이터
- Validity(정확성) : 데이터의 유효성 보장
- Volatility(휘발성) : 데이터의 의미 있는 기간

#### <mark style="background:#fff88f">빅데이터가 만들어내는 변화</mark>
- 표본조사 → <font color="#ff0000">전수조사</font>
- 사전처리 → <font color="#ff0000">사후처리</font>
- 질 → <font color="#ff0000">양</font>
- 인과관계 → <mark style="background:#fff88f"><strong><font color="#ff0000">상관관계</font></strong></mark>
- <font color="#245bdb">'전후양상'</font>

#### 빅데이터의 주요 분석기법
- 회귀분석 : 독립변수와 종속변수 간의 관계 분석 (나이가 매출에 어떤 영향을 미치는지)
- 분류분석 : 데이터가 어떤 그룹에 속하는지 판별 (스팸메일 구분)
- <font color="#ff0000">연관분석</font> : 여러 요소들 간의 규칙 **<font color="#ff0000">상관관계</font>** 존재. (마트에서 치킨과 맥주를 같이 사는 관계)
- <mark style="background:#fff88f"><strong><font color="#ff0000">유전자 알고리즘 : 최적화</font></strong></mark> 필요한 문제의 해결책.<font color="#ff0000"> 세대를 거듭하며 최적 결과를 찾아가는 방식</font>.(택배차량 어떻게 배치, 최대 시청률 얻으려면 어떤 프로그램을 어떤 시간대에 방송?)
- 기계학습 : 훈련 데이터로부터 컴퓨터가 학습하고 미래를 예측 (넷플릭스 영화 추천 시스템)
- 감정분석 : 텍스트 데이터에서 감정(긍정/부정)을 분석
- <strong>소셜 네트워크 분석</strong> : 사람간의 관계 (SNS상 사용자들 관계 속 영향력 높은 사람 찾기)
- 텍스트 마이닝 : 텍스트로부터 자연어처리(NLP)를 통한 숨겨진 의미 발견 (문서요약, 키워드추출)

#### 위기 요인과 통제방안
- **사생활 침해** : SNS 올린 데이터가 사생활 침해 → 제공자 동의에서 <strong><mark style="background:#fff88f"><font color="#ff0000">사용자 책임</font></mark></strong>으로 전환
- **책임 원칙 훼손** : 범죄 예측 프로그램으로 예측하여 체포하는 문제 → <font color="#ff0000">결과 기반 책임 원칙 고수</font>
- **데이터의 오용** : 분석 결과가 항상 옳은 것은 아님 → 알고리즘 접근 허용 및 알고리즘 해석가능한 <font color="#ff0000">알고리즈미스트</font> 필요
	- 알고리즈미스트 : 부당하게 피해가 발생한 사람들을 <font color="#ff0000">구제</font>하는 전문인력

#### 데이터 3법
- 개인정보보호법, 정보통신망법, 신용정보법
- <mark style="background:#fff88f"><font color="#ff0000">가명정보</font></mark>의 개념 도입(통계 작성, 연구, 공익적 기록보존 목적 하에 동의 없이 활용 가능)
- <font color="#245bdb">'개정신'</font>

#### 개인정보, 가명정보, 익명정보
- 개인정보 : 개인을 알아볼 수 있는 정보, 동의를 받아 활용 가능 (홍길동, 33세)
- <font color="#ff0000">가명정보</font> : <font color="#ff0000">가명처리</font>를 통해 추가정보 없이 특정 불가 (홍OO, 30대 초반)
- 익명정보 : 더 이상 개인을 알아볼 수 없는 정보, <font color="#ff0000">제한 없이 자유롭게 활용</font> (OOO, 30대)

#### <mark style="background:#fff88f"><font color="#ff0000">개인정보 비식별화</font></mark>
- 가명처리 (홍길동, 35세 → 임꺽정, 30세)
- 총계처리 (홍길동 170cm, 임꺽정 180cm → 평균 키 175cm)
- 데이터 삭제 (주민등록번호 901111-1234567 → 90년대 생, 남자)
- 데이터 범주화 (홍길동, 35세 → 홍길동, 30~40세)
- 데이터 마스킹 (홍길동, 35세 → 홍OO, 35세)

#### <mark style="background:#fff88f">빅데이터 활용 위한 3대 요소</mark>
- <font color="#ff0000">인력, 자원(데이터), 기술</font>
- <font color="#245bdb">'인자기'</font>

#### 빅데이터 분석 전략 인사이트 확보 방향
- Big에 초점을 맞추지 마라 : 분석 목적에 맞는 데이터 구성과 기법이 중요
- 전략적 인사이트 확보 : 단순 분석을 넘어서 실행 가능성 고려
- 가치 기반 분석 수행 : 일차원적 분석을 넘어 가치를 창출하는 다범위 분석 요구

#### 데이터 사이언스
- 데이터와 관련된 모든 분야의 전문지식을 종합한 학문
- 정형/비정형 데이터를 막론하고 데이터를 분석 (총체적 접근법)


#### 데이터 사이언스 핵심 구성요소
- 분석(<u>A</u>nalytics) : 수학, 확률, 머신러닝, 분석학 등
- <u>I</u>T : 프로그래밍, 데이터 엔지니어링, 컴퓨팅 등
- <u>비</u>즈니스 분석 : 커뮤니케이션, 스토리텔링, 시각화 등
- <font color="#245bdb">'AI비'</font>

#### <mark style="background:#fff88f"><font color="#ff0000">데이터 사이언티스트의 필요역량</font></mark>

- <font color="#ff0000">Soft Skill</font> : 통찰력(창의적 사고, 호기심, 비판), 설득력(스토리텔링, 시각화), 협력(커뮤니케이션)
- ※ 가트너가 제시한 역량 : 데이터 관리, 분석 모델링, 비즈니스 분석, 소프트 스킬
  - <font color="#245bdb">하드스킬은 이과적, 소프트 스킬은 문과적인 느낌</font>


#### 빅데이터 가치 패러다임 변화

#### <mark style="background:#fff88f">분석 기획시 고려사항</mark>
- 가용 데이터 파악 : 분석의 기본이 되는 데이터 확보 및 파악

### 분석 방법론
#### 분석 방법론의 구성요소
- <font color="#ff0000">절차, 방법, 도구와 기법, 템플릿과 산출물</font>

#### 분석 모델의 유형
- 계층적 프로세스 모델 : 단계(<font color="#ff0000">Baseline으로 관리</font>) → 태스크 → 스텝(단기간 수행 WorkPackage)
- 폭포수 모델 : 이전 단계 완료되어야 다음 단계 진행 (Top-Down)
- 프로토타입 모델 : <font color="#ff0000">일부분(프로토타입)을 우선 개발하고</font> 보완
- <font color="#ff0000"> 나선형 모델</font> : 여러 개발과정 거쳐 점진적으로 완성, <font color="#ff0000">위험요소</font> 제거 초점
- 애자일 : 짧은 개발 주기를 가지고 고객 피드백을 지속적으로 반영하여 반복적인 개발
	- <font color="#245bdb">계층적 프로세스 모델은 빅데이터 분석 방법론의 기반</font>

#### <mark style="background:#fff88f">KDD 분석 방법론</mark>
- <font color="#ff0000">비즈니스 도메인 이해 -> 데이터 선택 → 전처리 → 변환 → 마이닝(분석 실행) → 평가</font>
- 데이터 선택 : 원시데이터(Raw Data)나 DB에서 필요한 데이터 선택
- 전처리 : 이상값, 잡음 식별 및 데이터 가공
- 변환 : 변수 선택 및 차원축소
- 마이닝 : 알고리즘을 선택하여 분석 수행
- 평가 : 결과에 대한 해석, 결과가 충족되지 않으면 절차를 반복 수행

#### <mark style="background:#fff88f"><strong><font color="#ff0000">Crisp-DM 분석 방법론</font></strong></mark>
- <font color="#ff0000">업무 이해 → 데이터 이해 → 데이터 준비 → 모델링 → 평가 → 전개</font>
- <font color="#245bdb">'업데데이트모델평가전'</font>
- 업무 이해 : 업무 목적 파악, 상황파악, 목표 설정, 프로젝트 계획 수립
- <mark style="background:#fff88f"><strong><font color="#ff0000">데이터 이해</font></strong></mark> : 초기 데이터 수집, 기술 분석, <mark style="background:#fff88f"><strong><font color="#ff0000">EDA(데이터 탐색)</font></strong></mark>, 데이터 품질 확인
- <mark style="background:#fff88f"><strong><font color="#ff0000">데이터 준비 : 데이터 셋 선택 및 정제, 통합, 포맷팅</font></strong></mark>
- <mark style="background:#fff88f"><strong><font color="#ff0000">모델링</font></strong></mark> : <strong>모델링 기법 선택</strong>, <strong>테스트 계획 설계</strong>, <font color="#ff0000"><strong>모델 작성 및 평가</strong></font>
- 평가 : <font color="#ff0000">분석결과 평가, 모델링 과정 평가, <strong>모델 적용성 평가</strong></font>
- 전개 : 전개 계획, 모니터링 및 유지보수 계획 수립, 프로젝트 종료 보고서 작성, 프로젝트 리뷰
	- 평가 → 전개에서 <font color="#ff0000">위대한 실패</font>(업무 이해로 다시 돌아감) 발생 가능

#### <mark style="background:#fff88f"><strong><font color="#ff0000">빅데이터 분석 방법론</font></strong></mark>
![Pasted image 20261026204916.png](/assets/images/Pasted%20image%2020261026204916.png)
- 분석 기획
	- 비즈니스 이해 및 범위 설정 : SOW(Statement of Works) - 구조화된 프로젝트 정의서
	- 프로젝트 위험계획 수립 : <font color="#ff0000">회피, 전이, 완화, 수용</font>
	- <font color="#245bdb">'회전완수'</font>
- 데이터 준비
	- 데이터 스토어 설계 : 정형, 비정형, 반정형 데이터에 따른 효율적 저장소를 설계
- 데이터 분석
	- <font color="#ff0000">탐색적 데이터 분석(EDA)</font> : 기초 통계량 및 시각화를 통해 데이터 특성 파악
	- 모델링 : 분류, 회귀, 군집 등 알고리즘 적용

### 분석 과제 발굴
#### 하향식 접근 방법
- 문제가 주어지고 해답을 찾기 위해 진행
- <font color="#ff0000">문제탐색 → 문제정의 → 해결방안탐색 → 타당성 검토</font>
- <strong><font color="#ff0000">문제탐색</font></strong>
	- 비즈니스 모델 기반 탐색 : <font color="#ff0000">업무, 제품, 고객, 규제와 감사, 지원인프라</font>
	- <font color="#245bdb">'지원인프라 업무 중에 고객이 제품을 규제와 감사 했다.'</font>
	- 발굴 범위 확장
		- 거시적 관점 : <font color="#ff0000">STEEP</font>(사회, 기술, 경제, 환경, 정치)
		- 경쟁자 확대 관점 : 대체자, 경쟁자, 신규 진입자
		- 시장의 니즈 탐색 관점 : 고객, 채널, 영향자
		- 역량의 재해석 : 내부 역량, 파트너 네트워크
	- 내/외부 사례 참조
		- 외부 참조 모델 기반(벤치마킹), 분석 <font color="#ff0000">유스케이스(과거 유사한 사례)</font>
- **문제 정의** : 비즈니스 문제를 데이터 문제로 변환하여 정의
- **해결방안 탐색** : 기존 시스템 활용, 시스템 고도화, 인적 자원 확보, 아웃소싱 등
- **타당성 검토** : 경제적 타당성, 데이터 타당성, 기술적 타당성

#### <mark style="background:#fff88f">상향식 접근 방법</mark>
- 문제 정의 자체가 어려울 때, 사물을 그대로 인식
- <strong>데이터를 먼저 탐색하여 패턴이나 이상 징후를 발견하고, 이를 바탕으로 마지막에 문제를 정의</strong>
- 분석 주제 유형이 <font color="#ff0000">'통찰' 및 '발견'</font>일 때 사용하는 방식
- <font color="#ff0000">프로세스 분류 → 프로세스 흐름 분석 → 분석요건 식별 → 분석요건 정의</font>
- 상향식 접근법의 적용 방법 : <mark style="background:#fff88f"><strong><font color="#ff0000">비지도학습</font></strong></mark>, <mark style="background:#fff88f"><font color="#ff0000">프로토타입 접근법</font></mark>, <font color="#ff0000">디자인 사고</font>의 발산 단계

#### 혼합 접근 방법
- 발산 단계 : 상향식 접근 방법으로서, 가능한 방안들을 도출
- 수렴 단계 : 하향식 접근 방법으로서, 도출된 방안들을 분석
- ※ 디자인 싱킹 : 사용자 공감으로 시작해서 아이디어 발산/수렴 과정을 통해 발전하는 방식
	- 공감하기 → 문제정의 → 아이디어 도출 → 프로토타입 → 테스트

### 분석 프로젝트 관리 방안
#### 분석 과제에서 고려해야할 5가지 요소
- <font color="#ff0000">데이터 양, 속도, 데이터 복잡성, 분석 복잡성, 정확도/정밀도</font>
- <strong>정확도(Accuracy)와 정밀도(Precision)는 <font color="#ff0000">Trade-Off</font> </strong>관계(=서로 상충)
	- 정확도 : 모형의 결과와 실제 값의 차이가 작은 정도
	- 정밀도 : 모형을 반복하여 적용했을 때 결과가 일관되게 나오는 정도
	- <strong>분석 안정성 측면에서는 정밀도가 중요</strong>하고, <strong>분석 결과를 업무에 실제로 활용하는 측면에서는 정확도가 중요</strong>
- <font color="#245bdb">여기에서의 정확도와 정밀도는 3과목의 오분류표에서의 평가지표와는 다른 개념</font>

## 3과목
### 데이터 마트
#### <mark style="background:#fff88f"><font color="#ff0000">데이터 마트(DM)</font></mark>
- 특정 주제에 맞게 데이터를 모아 놓은 <mark style="background:#fff88f"><strong><font color="#ff0000">소규모 데이터 웨어하우스</font></strong></mark>
- <strong>데이터 마트는 데이터 웨어하우스의 일부</strong>로서, 특정 부서나 주제의 사용 목적에 맞게 필요한 데이터를 구성한 저장소
- 원천 데이터 수집 → 데이터 웨어하우스 → 데이터 마트

#### 요약변수와 파생변수
- **요약변수** : 수집된 정보를 종합한 변수로서 <font color="#ff0000">재활용성</font> 이 높음 (1개월간 수입)
- **파생변수** : 의미를 부여한 변수, <font color="#ff0000">논리적 타당성</font> 필요 (고객구매등급)


### 결측값 처리와 이상값 검색
#### EDA (탐색적 자료 분석)
- 데이터의 의미를 찾기 위해 <font color="#ff0000">통계, 시각화</font>를 통해 파악
- 데이터의 전반적인 구조를 파악하고 이상치 및 결측치를 발견하는 단계
- EDA의 4가지 주제
	- <u>저</u>항성의 강조 : 자료 변동에 민감하지 않음
	- <u>잔</u>차 계산 : 값들이 주경향으로부터 얼마나 벗어나 있는지 확인하는 척도
	- 자료변수의 <u>재</u>표현 : 원래 변수를 적정한 척도로 변환
	- 그래프를 통한 <u>현</u>시성 : 시각화를 통하여 효율적으로 파악
	- **<font color="#245bdb">'저잔재현'</font>


#### 결측값 처리
- 존재하지 않는 데이터, NULL/NA로 표시

##### <mark style="background:#fff88f">ESD</mark>(Extreme Studentized Deviation)
정규분포를 따른다고 할 때 <mark style="background:#fff88f"><strong>평균으로부터 표준편차의 3배를 넘어가는 데이터는 이상값</strong></mark>으로 판단
##### <mark style="background:#fff88f"><strong><font color="#ff0000">상자그림(사분위수)</font></strong></mark>
![Pasted image 20261030201634.png](/assets/images/Pasted%20image%2020261030201634.png)
- <strong><mark style="background:#fff88f">사분위수 범위(IQR)은 전체 데이터 가운데 50%가 분포하는 구간의 길이</mark></strong>를 나타냄
- <mark style="background:#fff88f"><strong><font color="#ff0000">평균, 데이터 관측치 개수는 알 수 없음</font></strong></mark>
- <mark style="background:#fff88f"><strong><font color="#ff0000">Q1 - 1.5IQR보다 작거나, Q3 + 1.5IQR보다 크면 이상값</font></strong></mark>. 상자 끝부터해서 계산.
- 수염은 울타리 안쪽에 있는 관측값 가운데 가장 작은 값과 가장 큰 값까지 그림.
-  Q1 - 3 x IQR 보다 작거나 Q3 + 3 x IQR 보다 큰 값은 <strong>극단적인 이상값</strong>
- **Z-Score**
	- 데이터를 표준화(평균 0, 표준편차 1) 후, 일정 임계 값을 초과할 경우 이상값으로 판단
- **DBScan**
	- 밀도를 이용하여 밀도가 적은 부분의 데이터를 이상값으로 판단


### 통계분석
#### 자료의 척도 구분
- 질적 척도
	- 명목척도 : 어느 집단에 속하는지 나타내는 자료 (대학교, 성별)
	- 순서척도(서열척도) : 서열관계가 존재하는 자료 (학년, 순위)
- 양적 척도
	- <mark style="background:#fff88f"><strong><font color="#ff0000">등간척도(구간척도)</font></strong></mark> : 간격이 일정하여 <mark style="background:#fff88f"><strong><font color="#ff0000">덧셈·뺄셈 비교가 가능</font></strong></mark>하지만 절대 영점이 없어 비율 비교는 불가능 (온도, 지수 등)
	- <mark style="background:#fff88f"><strong><font color="#ff0000">비율척도</font></strong></mark> : <font color="#ff0000">절대적 기준 0</font>이 존재하고 <font color="#ff0000">사칙연산 가능</font>, <font color="#ff0000">가장 많이 수집되는 자료</font> (무게, 나이 등)

#### 기초 확률의 이해
- 조건부 확률 : 특정 사건 B가 발생했을 때 A가 발생할 확률
	- $P(A\mid B) = P(A ∩ B)/P(B)$ (백신을 맞았을 때 감기에 걸릴 확률)
- <strong><mark style="background:#fff88f"><font color="#ff0000">독립사건</font></mark></strong> 
	- A, B가 서로 영향을 주지 않는 사건( <font color="#ff0000">P(A\mid B) = P(A)</font> )
	- <strong><mark style="background:#fff88f"><font color="#ff0000">P(A ∩ B) = P(A)P(B)</font></mark></strong> (주사위 A가 3이 나왔을 때, 주사위 B가 3이 나올 확률)
- <font color="#ff0000">배반사건</font>
	- A, B가 서로 동시에 일어나지 않는 사건
	- P(A ∩ B) = ∅ (동전을 던졌을 때 앞면과 뒷면이 동시에 나올 확률)
- 독립사건이라고 해서 배반사건이 아니고, 배반사건이라고 독립사건은 아니다.<font color="#ff0000"> 단, 두 사건의 확률이 모두 0보다 크면 배반사건과 독립 사건이 동시에 성립할 수 없다.</font>

#### 기초 통계의 이해
- 확률변수 : 표본공간의 각 원소에 해당하는 값(확률)을 대응하는 함수
	- 예) 주사위 던지는 눈의 수는 1~6까지이며, 이는 확률변수 $X$의 가능한 값
- 이산확률분포 : 0, 1, 2, 3 처럼 셀 수 있는 확률변수에 확률이 대응
- 분산 : 각 값이 평균에서 얼마나 떨어져 있는지를 구한 값 ( $V(X) = E(X^2) - [E(X)]^2$ )
-  <font color="#ff0000">이항분포</font> : 연속된 $n$번의 독립적 시행에서 각 시행 확률 $p$를 가질 때의 이산확률분포
	- 이항분포의 평균 : $\mu = np$ , 이항분포의 분산 : $\sigma^2 = np(1 - p)$
- <font color="#ff0000">정규분포</font> : 자연 현상이나 통계 데이터에서 자주 나타나는 대표적인 연속확률분포 ($\color{red}{N(\mu, \sigma^2)}$)
- <font color="#ff0000">표준정규분포</font> : 정규분포 중에서도 평균이 0, 표준편차가 1인 특별한 분포
	- $\color{red}{Z = \frac{X-\mu}{\sigma} \sim N(0,1)}$

#### 분산 정도 측면
- 범위 : 최댓값에서 최솟값을 뺀 값이며, <font color="#ff0000">이상치에 민감</font>
- 표준편차 : 분산에 제곱근을 취한 값, 원래 단위와 같아 해석이 용이
- <font color="#ff0000">변동계수(CV)</font> : <font color="#ff0000">표준편차에서 평균을 나눈 백분율</font>, 단위 다른 변수간 상대적 비교에 유용


#### <font color="#ff0000">공분산</font>
- 두 확률변수의 상관정도
 - $공분산 = 0$ : 상관이 전혀 없는 상태
- $공분산 > 0$ : 양의 상관관계
- $공분산 < 0$ : 음의 상관관계
- <font color="#ff0000">최소, 최대값이 없어</font> 강약 판단 불가
- <mark style="background:#fff88f"><strong><font color="#ff0000">두 변수가 독립이면 공분산은 0</font></strong></mark>이지만, <font color="#ff0000">공분산이 0이라고 두 변수가 독립이라고 할 수는 없음</font>
- 공분산의 크기는 변수의 측정 단위에 따라 달라진다.


#### <font color="#ff0000">상관계수</font>
- 공분산의 단위와 범위 영향을 <font color="#ff0000">표준화</font>하여, 상관정도를 $-1 \sim 1$값으로 표현
	- $상관계수 = 1$ : 양의 선형 관계
	- $상관계수 = 0$ : 상관없음
	- $상관계수 = -1$ : 음의 선형 관계
		- 한 변수가 증가할 때 다른 변수가 감소하는 경향을 의미할 뿐 수학적 반비례 관계를 의미하지 않는다.
- 두 변수 x와 y의 상관계수가 0.2일 때, −2x + 1과 y − 1의 상관계수?
	- 상관계수는 각 변수에 상수를 더하거나 빼도 변하지 않는다.
	- <font color="#ff0000">변수에 상수를 곱하면 상관계수의 부호는 곱한 상수들의 부호에 따라 결정</font>된다.
	- x에 −2, y에 1을 곱했으므로 부호가 한 번 바뀌어 −0.2가 된다.

#### 첨도와 왜도

- <font color="#ff0000">첨도는 a의 부호와 관계없이 변하지 않음.</font> 
- 왜도는 a>0이면 변하지 않지만, a<0이면 부호가 반대로 바뀜.

- 모집단 → 표본추출 → 표본집단 → 모집단 예측(추정, 가설검정)

#### <mark style="background:#fff88f"><strong><font color="#ff0000">표본추출 방법</font></strong></mark>
- 랜덤 추출법(=단순 무작위 추출법) : 무작위로 표본 추출. 모든 개체의 선택 확률이 동일.
- <mark style="background:#fff88f"><strong><font color="#ff0000">계통 추출법</font></strong></mark>
	- 모집단에 <mark style="background:#fff88f"><strong><font color="#ff0000">번호를 부여</font></strong></mark>한 후, 첫 표본을 무작위로 선정한 뒤 <mark style="background:#fff88f"><strong><font color="#ff0000">일정한 간격(매 k번째)으로 표본을 추출</font></strong></mark>하는 방법.
- <mark style="background:#fff88f"><strong><font color="#ff0000">집락 추출법(=군집 추출법)</font></strong></mark>
	- 여러 군집으로 나눈 뒤 군집을 선택하여 랜덤 추출
	- **군집 내 이질적 특징, 군집 간 동질적 특징**
	- 예) 아파트 
- <mark style="background:#fff88f"><strong><font color="#ff0000">층화 추출법</font></strong></mark>
	- **군집 내 동질적 특징, 군집 간 이질적 특징**
	- 같은 비율로 추출 시, 비례 층화 추출법
	- 예) 학년 추출
- 복원, 비복원 추출
	- 복원 추출 : 추출되었던 데이터를 <font color="#ff0000">다시 포함시켜</font> 표본 추출
	- 비복원 추출 : 추출되었던 데이터를 제외하고 표본 추출

#### 표본오차 비표본오차
- **표본오차 (Sampling Error)**
	- 모집단 전체가 아닌 일부 표본을 추출하여 조사하기 때문에 발생하는 오차
	- <strong>표본 크기를 늘리면 줄일 수 있음</strong>
	- 표본 크기가 커질수록 표본 오차는 0에 가까워짐
- **비표본오차 (Non-sampling Error)**
	- 조사 과정에서 발생하는 표본오차 이외의 오차
	- 측정 오류, 응답 오류, 무응답, 조사원의 실수 등
	- <strong>표본 크기를 늘려도 반드시 감소하지 않음</strong>
	- 표본의 크기나 추출 방법에 관계없이 발생 가능
- <font color="#245bdb">전수조사도 비표본 오차(측정·집계 오류)는 피할 수 없으며, 표본조사의 품질은 두 오차를 함께 관리해야 한다.</font>

### 확률분포
#### 이산 확률분포
- <strong>베르누이, 이항, 기하, 음이항, 초기하, 포아송 분포</strong>
- 값을 셀 수 있는 분포, 확률질량함수로 표현
- <mark style="background:#fff88f"><strong>확률 질량 함수의 값은 0 이상 1 이하</strong></mark>, 모든 가능한 확률의 합: 1
	- 확률질량함수 : 각각의 특정한 값이 발생할 확률
- 베르<u>누</u>이분포 : 결과가 두 가지 중 한가지로 나타나는 베르누이시행으로 나타나는 분포
	- 예) 동전 던지기, 시험의 합격/불합격
- 이항분<u>포</u> : $N$번의 베르누이시행 중 $K$번 성공할 확률의 분포
	- 예) 동전을 20번 던져 앞면이 나오는 횟수
- 기하분<u>포</u> : 성공확률이 $p$인 베르누이시행에서 처음으로 성공할 때까지 시행횟수의 분포
	- 예) 동전을 던져 처음으로 앞면이 나오기까지 던진 횟수
- 음이<u>항</u>분포 : 성공확률이 $p$인 베르누이시행을 $r$번 성공할 때까지 반복 시행횟수의 분포
	- 예) 동전을 던져 앞면이 5번 나오기까지 던진 횟수
- 초기<u>하</u>분포 : $N$개 중 비복원추출로 $n$번 추출했을 때 원하는 결과가 $k$번 나올 확률의 분포
	- 예) 10개 구슬 중 4개의 구슬이 당첨 구슬일 때, 4번 뽑았을 때 당첨 구슬을 2번 뽑을 확률
- 다<u>항</u>분포 : $N$번 시행에서 각 시행이 여러 개의 결과를 가질 수 있는 확률 분포
	- 예) 주사위를 20번 던져 각 면이 나오는 횟수
- <u>포</u>아송분포 : 단위 시간 내 발생할 수 있는 사건의 발생 횟수에 대한 분포
	- 예) 하루동안 발생하는 출생자 수, 한 시간 동안 사무실에 걸려온 전화의 수
- <font color="#245bdb">'누포항하'</font>

#### 연속 확률분포
- <strong>균일, 정규, 지수, 감마, 베타 t, 카이제곱, F 분포</strong>
- 값을 셀 수 없는 분포, 확률밀도함수로 표현.
- <strong><mark style="background:#fff88f">확률 밀도 함수의 값은 1보다 클 수 있다.</mark></strong> <strong><mark style="background:#fff88f">함숫값이 0 이상이고 전체 면적이 1</mark></strong>이기만 하면 된다.
	- 확률 밀도 함수 : 특정 구간에 확률이 얼마나 밀집되어 있는지를 나타내는 밀도.
- 균일분포 : 모든 값 동일한 확률
- <font color="#ff0000">정규분포</font> : 우리가 일상생활에서 흔히 보는 확률변수의 평균 분포를 근사한 분포
- <font color="#ff0000">t분포</font> : 정규분포와 유사하지만, 꼬리 부분이 더 두껍고 긴 분포
	- (T검정 활용) <font color="#ff0000">표본이 30개 보다 작은 집단</font>에 대한 평균 검정
- 카이제곱분포 : 독립적인 정규분포를 따르는 변수들의 제곱합으로 구성된 분포
	- (카이제곱 검정 활용) 두 집단의 동질성 검정, 단일 집단의 모분산 검정
- F분포 : 두 개의 서로 다른 카이제곱 분포의 비율
	- (F검정 활용) 두 집단의 분산 동질성 검정
- <strong>지수분포</strong> : 사건 간 시간 간격 분포
- 감마분포 : 지수분포의 일반화
- 베타분포 : 두 모수 $\alpha, \beta$에 대한 0~1사이 비율 분포

#### 확률분포의 기댓값
 - 이산적 확률변수 : $\color{red}{E(X) = \sum xf(x)}$
	 - E(X) = 1×1/6 + 2×1/2 + 3×1/3 = 1/6 + 6/6 + 6/6 = 13/6
- 연속적 확률변수 : $\color{red}{E(X) = \int xf(x)}$

#### 중심극한정리
- 임의의 모집단으로부터 추출된 표본분포는 표본크기가 충분히 크면(30개 이상) 정규분포
- <font color="#ff0000">모집단의 분포에 상관없이</font> 표본평균분포가 정규분포를 이룸

#### 표본평균의 표본분포
- 표본평균의 기댓값 : $E(\bar{X}) = \mu$
- 표본평균의 분산 : $V(\bar{X}) = \frac{\sigma^2}{n}$
- 표본평균의 표준편차(=표준오차) $= \sigma_{\bar{X}} = \frac{\sigma}{\sqrt{n}}$ 
	-  표준오차 : 표본을 반복 추출했을 때 표본 통계량(예: 표본평균)이 얼마나 변동하는지를 나타내는 값.
- 표본평균의 표준화 : $Z = \frac{\bar{X}-\mu}{\frac{\sigma}{\sqrt{n}}} \sim N(0,1)$
- ($\mu$ : 모집단의 평균, $\sigma$ : 모집단의 표준편차, $\bar{X}$ : 표본평균, $n$ : 표본의 크기)

### 통계적 추론
#### 점추정
- 모집단이 특정한 값으로 추정하며, <font color="#ff0000">추정량(Estimator)으로 모수를 추정</font>
- 추정량의 조건
	- <u>불</u>편성(Unbiasedness) : 추정량의 기댓값이 실제 모수와 같음 (<font color="#ff0000">편향이 0이 되는 경우</font>)
	- <u>효</u>율성(Efficiency) : 여러 추정량 중 분산이 작은 것이 더 효율적인 추정량
	- <u>일</u>치성(Consistency) : 표본 크기가 증가할수록 추정량이 모수에 가까워짐
	- <u>충</u>족성(Sufficiency) : 추정량이 모집단의 정보를 최대한 반영
	- <font color="#245bdb">'불효일충'</font>
- 대표적인 추정량
	- 모집단의 평균 $\mu \rightarrow$ 표본평균 $\bar{X} = \frac{1}{n}\sum X$
	- 모집단의 분산 $\sigma^2 \rightarrow$ 표본분산 $s^2 = \frac{1}{n-1}\sum(X - \bar{X})^2$

#### <mark style="background:#fff88f"><strong><font color="#ff0000">구간추정</font></strong></mark>
- <mark style="background:#fff88f"><strong><font color="#ff0000">일정한 신뢰 수준 하에서 모수가 포함될 것으로 기대되는 범위를 정하여 모수를 추정</font></strong></mark>
- <mark style="background:#fff88f"><font color="#ff0000">신뢰수준 ↑ → 신뢰구간 길이 ↑ +  정밀도↓ </font></mark> : 표본의 크기가 일정할 때, 신뢰수준을 높이면 신뢰구간의 길이는 길어진다. 
- <mark style="background:#fff88f"><font color="#ff0000">표본 크기 n↑ → 신뢰구간 길이 ↓</font></mark> : 신뢰수준이 일정할 때, 표본의 크기가 커질수록 신뢰구간의 길이는 더 좁아진다.
- 95% 신뢰구간의 올바른 해석: 같은 방식으로 100번 구간을 만들면 그중 약 95개의 구간이 참 모수를 포함한다.
- 모집단이 특정한 구간으로 추정 (95%, 99%를 가장 많이 사용)
- 모집단의 분산을 알고 있는 경우
	- $\bar{X} - Z_{\frac{\alpha}{2}}\frac{\sigma}{\sqrt{n}} \le \mu \le \bar{X} + Z_{\frac{\alpha}{2}}\frac{\sigma}{\sqrt{n}}$
	- 신뢰수준 95% : $Z_{\frac{\alpha}{2}} = 1.960$
	- 신뢰수준 99% : $Z_{\frac{\alpha}{2}} = 2.576$
- 모집단의 분산을 모르는 경우
	- <font color="#ff0000">자유도가 n-1인 t분포</font>를 이용하여 신뢰구간을 추정
	- $\bar{X} - t_{\frac{\alpha}{2}, n-1}\frac{S}{\sqrt{n}} \le \mu \le \bar{X} + t_{\frac{\alpha}{2}, n-1}\frac{S}{\sqrt{n}}$ ($S$ : 표본표준편차)
- 신뢰수준 : 동일한 방법으로 구간을 반복 추정했을 때 그 구간들이 모수를 포함하는 비율.

### 가설 검정
![Pasted image 20261030205609.png](/assets/images/Pasted%20image%2020261030205609.png)
- <mark style="background:#fff88f"><strong><font color="#ff0000">검정통계량</font></strong></mark>(Test Statistic)
	- <strong>표본 데이터를 이용하여 계산하며, <mark style="background:#fff88f">귀무가설의 기각 여부를 판단하는 기준이 되는 통계량</mark></strong>
	- 검정 통계량이 표본으로부터 하나의 값으로 산출되는 것은 맞지만, 그 값 자체로 기각 여부를 판단하는 것이 아니라 귀무가설 하의 분포(p-value)와 비교하여 판단한다.
	- Z검정 : Z통계량
	- t검정 : t통계량
	- 카이제곱 검정 : χ² 통계량
	- 분산분석(ANOVA) : F통계량
- 귀무가설($H_0$) : 일반적으로 생각하는 가설 (차이가 없다)
- 대립가설($H_1$) : 귀무가설을 기각하는 가설, <font color="#ff0000">증명하고자 하는 가설</font> (차이가 있다, 크다/작다)
- <mark style="background:#fff88f"><strong><font color="#ff0000">유의수준</font></strong></mark>($\color{red}\alpha$) : 귀무가설이 참일 때 기각하는 <mark style="background:#fff88f"><strong><font color="#ff0000">1종 오류를 범할 확률의 최대 허용 한계</font></strong></mark> (일반적 0.05)
	- <strong>유의수준을 너무 작게 설정하면 2종 오류를 범할 확률이 높아짐.</strong>
-  <mark style="background:#fff88f"><strong><font color="#ff0000">p-value</font></strong></mark> : <mark style="background:#fff88f"><strong><font color="#ff0000">귀무가설을 지지 하는 정도</font></strong></mark>를 나타내는 확률
	- p-value는 귀무가설 하에서 관측 결과 이상으로 극단적인 값이 나올 확률이며, <font color="#ff0000">작을수록 귀무가설에 불리한 증거</font>이다.
- <strong>1종 오류</strong>($\alpha$) : 귀무가설이 참인데 기각하는 오류.
- <strong>2종 오류</strong>(β) : 귀무가설이 거짓인데 채택하는 오류.
- <strong>검정력(1 − β)</strong> : 대립가설이 참일 때 귀무가설을 올바르게 기각할 확률
	- 표본 크기 증가 → 표준오차$(SE=\frac{\sigma}{\sqrt{n}})$ 감소
		- 표준오차 : 표본 평균이 얼마나 흔들리는지를 나타내는 지표
	- 표준오차 감소 → 검정력 증가
	- 검정력 증가 → β 감소
	- α를 일정하게 유지하면서 β를 감소시킬 수 있음
	- <font color="#245bdb">같은 유의수준에서 표본 크기를 늘리면 α를 유지하면서 β를 줄여 검정력을 높일 수 있다.</font>
- <font color="#ff0000">표본의 크기가 커질수록 아주 작은 차이도 통계적으로 유의해질 수 있다.</font>

#### 가설 검정 R결과 해석
- 귀무가설 / 대립가설 설정
	- ‘차이가 없다’ 혹은 ‘동일하다’ → 귀무가설
- 양측 혹은 단측검정 확인
	- 대립가설의 값이 ‘같지 않다’ → 양측검정 / ‘값이 크다’, ‘값이 작다’ → 단측검정
- 일표본 혹은 이표본 확인
	- 하나의 모집단 → 일표본 / 두개의 모집단 → 이표본
- <font color="#ff0000">귀무가설 기각 혹은 채택</font>
	- **p-value < 유의수준(𝑎)** : 귀무가설 기각
	- **p-value > 유의수준(𝑎)** -> 귀무가설 채택
- <mark style="background:#fff88f"><strong><font color="#ff0000">t검정</font></strong></mark>인 경우 - 단일표본, 대응표본, 독립표본 확인
	- 모집단에 대한 평균검정 → 단일표본
	- <mark style="background:#fff88f"><strong><font color="#ff0000">동일 모집단</font></strong></mark>에 대한 평균비교 검정 → <mark style="background:#fff88f"><strong><font color="#ff0000">대응표본</font></strong></mark>
	- <font color="#ff0000">서로 다른 모집단</font>에 대한 평균비교 검정 → <font color="#ff0000">독립표본</font>

#### 모수 검정
- 모집단이 특정한 분포(보통 정규분포)를 따른다고 가정하고 수행하는 가설검정
- 예)  두 학교의 학생들의 수학 점수에 대한 t검정
  ![Pasted image 20261030210733.png](/assets/images/Pasted%20image%2020261030210733.png)
- 귀무가설/대립가설 설정
	- ‘차이가 없다’ 혹은 ‘동일하다’ → 귀무가설로 설정
	- <font color="#ff0000">두 학교의 성적은 동일하다</font>
- 양측 혹은 단측검정 확인
	- alternative hypothesis <font color="#ff0000">not equal</font> to 0 : 대립 가설 값이 같지 않다
	- 대립가설의 값이 같지 않다 → <font color="#ff0000">양측검정</font>
	- 귀무가설(H₀): 두 학교의 평균 차이 = 0 (평균이 같다)
	- 대립가설(H₁): 두 학교의 평균 차이 ≠ 0 (평균이 다르다)
	- 신뢰구간의 하한(-10.29)과 상한(5.53). 두 학교 평균 차이(A − B)의 95% 신뢰구간이에요.
		- 실제 모평균 차이가 -10.29 ~ 5.53 사이에 있을 거라고 95% 신뢰한다는 뜻
		- 표본 차이: 61.91 − 64.30 = -2.38이고, 이 값이 구간의 가운데쯤 있음.
- 일표본 혹은 이표본 확인
	- 두개의 모집단 → <font color="#ff0000">이표본</font>
- 귀무가설 기각 혹은 채택
	- conf.level = 0.95 -> a = 0.05
	- $p\text{-value} : 0.5515 > \text{유의수준}(\alpha) : 0.05 \rightarrow$ <font color="#ff0000">귀무가설 채택</font>
- 단일표본, 대응표본, 독립표본 확인
	- 서로 다른 모집단에 대한 평균비교 검정 → <font color="#ff0000">독립표본</font>
	- <font color="#245bdb">독립표본 t-검정은 두 집단의 분산이 같다는 가정(등분산 가정)이 전제가 되며, 등분산을 가정하지 않는 경우 welch의 t-검정을 사용</font>

#### 비모수 검정
- 모집단에 대한 아무런 정보 없어, 관측 자료가 특정 분포를 따른다고 가정 불가 시 검정
- 두 관측 값의 <font color="#ff0000">순위나 차이로</font> 검정
- <font color="#ff0000">부호검정, 순위합검정, 맨-휘트니 U검정, 크루스칼-왈리스 검정, 콜모고로프-스미르노프 검정, 카이제곱 검정</font>

##### 카이제곱 검정(교차분석)
- <mark style="background:#fff88f"><strong><font color="#ff0000">범주형 변수</font></strong></mark>간의 검정에 주로 활용되며, 적합도(한 변수의 분포), 독립성(두 변수의 관련성), 동질성(집단 간 분포 비교) 검정에 활용
- <font color="#ff0000">관측빈도와 기대빈도 차이를 측정</font>
- 독립성 검정 : 두 범주형 변수 간에 서로 관련이 있는지 아니면 통계적으로 서로 독립적인지 판단하기 위해 수행
- 동질성 검정 : 서로 다른 관찰 집단 간에 해당 변수의 분포가 동일한지를 확인하기 위해 수행


### 회귀분석
- 독립변수들이 종속변수에 영향을 미치는지 파악하는 분석방법
	- 독립변수 : 원인을 나타내는 변수 ($x$)
	- 종속변수 : 결과를 나타내는 변수 ($y$)
	- 잔차(오차) : 실제값 - 예측값
		- <strong>절편이 있는 최소 제곱</strong>에서는 <strong>잔차의 합이 0</strong>이 되므로 <strong>잔차의 평균은 0</strong>이다.
		- <strong>잔차는 독립변수와 서로 상관되지 않아야한다.</strong>
		- <strong>오차항이 평균 0인 정규분포를 따른다고 가정</strong>한다.
		- 최소제곱 잔차는 독립변수 및 적합값과 직교(= 상관계수 0)하지만, <mark style="background:#fff88f"><strong><font color="#ff0000">종속변수와는 일반적으로 양의 상관</font></strong></mark>을 가진다.
		- <font color="#ff0000">잔차가 U자형 곡선 패턴</font>을 보이는 것은 선형모형이 포착하지 못한 비선형(곡선) 관계가 남아 있다는 신호이므로, <font color="#ff0000">변수 변환이나 비선형 모형의 적용을 고려</font>해야 한다.
		- 잔차 진단
			- 곡선 패턴: 비선형성(다항항·변환 추가)
			- 깔때기 패턴: 이분산성(가중회귀·변환)
			- 시점에 따른 패턴: 자기상관(시계열 모형).
	- 회귀분석은 독립변수와 종속변수간의 상관관계를 분석하는 방법이며, <mark style="background:#fff88f"><strong><font color="#ff0000">인과관계를 보장하지 않음</font></strong></mark>
- <strong><mark style="background:#fff88f"><font color="#ff0000">회귀계수 추정방법</font></mark></strong>
	- <strong><mark style="background:#fff88f"><font color="#ff0000">최소제곱법(=최소자승법)</font></mark></strong> : <font color="#ff0000">잔차의 제곱합(SSE)이 최소</font>가 되는 회귀계수와 절편을 구하는 방법
- 회귀모형 평가
	- <strong><mark style="background:#fff88f"><font color="#ff0000">R-square(결정계수)</font></mark></strong> : <strong>총 변동 중에서 회귀모형에 의하여 설명되는 변동이 차지하는 비율</strong> (<mark style="background:#fff88f"><strong><font color="#ff0000">0 ~ 1</font></strong></mark>)

#### 설명 변수가 1개인 단순선형 회귀
- 설명변수가 1개인 단순선형회귀에서는 모형 전체의 F 검정과 기울기의 t 검정이 같은 가설(기울기 = 0)을 검정한다. 따라서 <mark style="background:#fff88f"><strong><font color="#ff0000">F 통계량은 t 통계량의 제곱과 같고 두 p-value도 같음</font></strong></mark>

#### 회귀분석 종류
- 단순회귀 : 1 개의 독립변수와 종속변수의 선형관계
- <font color="#ff0000">다중회귀</font> : 2 개 이상의 독립변수와 종속변수의 선형관계
- <font color="#ff0000">다항회귀</font> : 2 개 이상의 독립변수와 종속변수가 2차 함수 이상의 관계
- <font color="#ff0000">규제항이 포함된 회귀</font>
	- <mark style="background:#fff88f"><strong><font color="#ff0000">라쏘회귀(L1 규제)</font></strong></mark> : L1 규제항을 포함 -  $\sum \lvert W \rvert$
	- <mark style="background:#fff88f"><strong><font color="#ff0000">릿지회귀(L2 규제)</font></strong></mark> : L2 규제항을 포함 - $\sum W^2$
	- <mark style="background:#fff88f"><strong><font color="#ff0000">엘라스틱넷</font></strong></mark> : L1 과 L2 를 동시에 규제
- <font color="#ff0000">교호항이 포함된 회귀</font> : 독립변수들의 <font color="#ff0000">교호작용</font>이 포함된 회귀 모형
	- 교호작용 : <font color="#ff0000">두 개 이상의 독립변수가 상호작용</font>을 하여, 종속변수에 영향을 미치는 경우

#### 선형회귀분석의 가정
- <u>선</u>형성 : 종속변수와 독립변수는 선형관계
- 등<u>분</u>산성 : 오차의 분산이 고르게 분포
- <u>정</u>규성 : 오차가 정규분포의 특성을 지님
- <u>독</u>립성 : 오차가 서로 독립
  - <font color="#245bdb">'선분정독'</font>

#### <mark style="background:#fff88f"><strong><font color="#ff0000">다중공선성 문제</font></strong></mark>
- <strong>독립변수들간 강한 상관관계</strong>로 회귀계수 추정이 불안정해지는 문제
- 설명변수 간 상관계수는 다중공선성 진단에 활용
- 다중공선성이 존재하면 <strong>회귀계수 추정량의 분산이 크게 팽창하여 추정이 불안정해진다.</strong>
- 진단 방법
	- 변수간 상관계수 절댓값이 0.8 이상이면 의심
	- <mark style="background:#fff88f"><font color="#ff0000">VIF(분산팽창인수) 값이 10 이상</font></mark>이면 다중공선성 존재한다고 판단 ( $VIF = \frac{1}{1-R^2}$ )
	- <font color="#ff0000">R(0~1) 커지면 VIF도 커짐</font>
	- <font color="#ff0000">조건수가 30 이상이면 의심</font>
- 해결방안 : 독립변수 제거, 차원 축소, 변수 선택, 상관 높은 변수 제거, 주성분 분석(PCA), <strong>정규화 회귀</strong>(<mark style="background:#fff88f"><strong><font color="#ff0000">라쏘, 릿지, 엘라스틱넷</font></strong></mark>)

#### 최적의 회귀 방정식 탐색 방법
- 전진선택법 : 변수를 하나씩 추가하면서 최적의 회귀방정식을 찾아내는 방법
- 후진제거법 : 변수를 하나씩 제거하면서 최적의 회귀방정식을 찾아내는 방법
- 단계별 선택법 : 전진선택법 + 후진제거법으로 변수를 추가할 때 벌점을 고려
	- AIC (아카이케 정보 기준) : 편향과 분산이 최적화 되는 지점 탐색, 자료가 많을수록 부정확
	- BIC (베이즈 정보 기준) : AIC를 보완했지만 AIC보다 큰 패널티를 가지는 단점
	- Mallow’s Cp : SSE(잔차 제곱합)을 활용한 판단
	- <font color="#245bdb">AIC와 BIC 모두 작을수록 좋음</font>


#### SST, SSE, SSR
![Pasted image 20261030151037.png](/assets/images/Pasted%20image%2020261030151037.png)
- SST : 전체의 변동. 회귀(SSR) + 잔차(SSE)
- SSR(회귀) : 모형에 의해 설명되는 변동. 예측값 $\hat{Y}$ 이 전체 평균($\bar{Y}$)에서 얼마나 멀리 떨어져 있는지
- SSE(잔차) : 모형에 의해 설명되지 않는 변동. 실제 데이터 값($Y$)이 모델의 예측값($\hat{Y}$)에서 얼마나 벗어나 있는지.

#### <mark style="background:#fff88f"><strong><font color="#ff0000">회귀분석의 분산분석(ANOVA)표</font></strong></mark>
![Pasted image 20261030150807.png](/assets/images/Pasted%20image%2020261030150807.png)
- <mark style="background:#fff88f"><strong><font color="#ff0000">ANOVA 검정</font></strong></mark> : <strong>3개 이상의 그룹의 평균을 비교</strong>하는 검정. (<font color="#ff0000">회귀모형의 유의성 분석 시 활용</font>)
	- ANOVA의 귀무가설은 모든 집단 평균이 같다는 것
	- 유의한 경우 적어도 한 집단의 평균이 다르다고 판단. 
	- <mark style="background:#fff88f"><strong><font color="#ff0000">구체적으로 어느 집단 간에 차이가 있는지는 알 수 없으며</font></strong></mark>, 사후검정을 통해 확인한다.
- <font color="#ff0000">전체 데이터 수 = 자유도 + 1</font>
- 회귀 자유도: p(추정해야하는 회귀계수의 개수. <font color="#ff0000">단순 회귀에서 p 는 1</font>) 
- <strong><mark style="background:#fff88f">결정계수(R-Square)</mark></strong> = $\color{red}R^2 = \frac{SSR}{SST}$ 
- <strong><mark style="background:#fff88f">수정된 결정계수</mark></strong> = $1 - \frac{(n-1)\,MSE}{SST}$
	- <strong>다중회귀분석</strong>에서는 독립변수의 수가 늘어나면 결정계수가 무의미하게 높아지는 단점을 보완하기 위해 수정된 결정계수를 평가지표로 활용
	- <font color="#ff0000">수정된 결정계수는 변수 수 증가에 따른 R² 과대평가를 보정</font>
	- <font color="#245bdb">다중 회귀에서는 수정된 R-square 값을 일반적으로 사용</font>
- F비(F-ratio, F값) : 회귀모형이 설명하는 변동이 설명 못 하는 변동에 비해 얼마나 큰지 보는 비율
- SSR = ∑(Ŷ - Y)²
- SSE = ∑(Y - Ŷ)²
- SST = SSR + SSE
- MSR = SSR/ p
- <mark style="background:#fff88f"><strong><font color="#ff0000">MSE = SSE / n-p-1</font></strong></mark>
- F = MSR/ MSE

#### <mark style="background:#fff88f"><strong><font color="#ff0000">회귀 모형의 검정</font></strong></mark>
- 독립변수와 종속변수 설정
- 회귀계수 값의 추정
- 모형 적합성 판단: 결정계수·수정 결정계수, F-검정(모형 전체 유의성), t-검정(개별 계수), 잔차 진단(정규성·등분산성·독립성).
- <mark style="background:#fff88f"><strong><font color="#ff0000">잔차 그래프(잔차산점도)</font></strong></mark>를 통해 오차 등분산성과 독립성 등 <font color="#ff0000">모형의 가정을 점검</font>할 수 있음
	- 잔차가 특정 패턴 없이 <font color="#ff0000">무작위로 분포하면 모형의 가정이 충족</font>된 것으로 판단
- <mark style="background:#fff88f"><strong><font color="#ff0000"><font color="#ff0000">모형 전체 유의성</font></font></strong></mark> : 모형에 대한 <strong><mark style="background:#fff88f"><font color="#ff0000">F 통계량, p-value</font></mark></strong>
	- 귀무가설 : ‘<font color="#ff0000">모든 회귀계수는 0 이다</font>’
- <mark style="background:#fff88f"><strong><font color="#ff0000">회귀계수 유의성</font></strong></mark>  : 회귀계수들의 <mark style="background:#fff88f"><strong><font color="#ff0000">t 통계량, p-value</font></strong></mark>
	- 각각의 회귀계수에 대한 귀무가설 : ‘<font color="#ff0000">회귀 계수는 0 이다</font>’
- 위 두 검정(F검정, t검정)의 귀무가설을 모두 기각하면 해당 모델을 활용
- 모형이 설명력을 갖는가 : <font color="#ff0000">결정계수(R square)</font> 값
- 통계적 유의성과 실질적(실무적) 유의성은 다르며, 효과 크기(effect size)를 함께 확인해야 한다.

#### <mark style="background:#fff88f"><strong><font color="#ff0000">주성분 분석 (PCA)</font></strong></mark>
- 상관성 높은 변수들의 <font color="#ff0000">선형 결합</font>으로 차원을 축소하여 새로운 변수를 생성

	- <mark style="background:#fff88f"><strong>제 1 주성분은 전체 데이터의 변동을 가장 많이 설명하는 축</strong></mark>
	- <mark style="background:#fff88f"><strong>주성분 번호가 커질수록 분산은 감소</strong></mark>

- <strong>주성분 선택 기준</strong> : 누적 분산 비율(통상 <mark style="background:#fff88f"><font color="#ff0000">70~90%</font></mark>), <mark style="background:#fff88f"><strong>고유값 1 이상</strong></mark>(Kaiser 기준), <mark style="background:#fff88f"><strong>Scree plot의 엘보 지점.</strong></mark>
	- 고유값 : 각 주성분이 설명하는 분산의 크기
- 주성분 분석을 통해 차원을 축소시켜 <font color="#ff0000">다중공선성 문제를 해결</font>할 수 있음.

#### 상관행렬을 이용한 PCA (고유값·고유벡터)
- 변수를 표준화하면 <font color="#ff0000">공분산행렬 = 상관행렬</font>이므로, 상관행렬의 고유값 분해로 주성분을 구함
- <font color="#ff0000">고유값(λ) = 주성분의 분산</font>, <font color="#ff0000">고유벡터 = 주성분의 계수(가중치)</font>
- 고유값이 큰 순서대로 제1, 제2 주성분 (λ₁ ≥ λ₂ ≥ …)
- 주성분끼리는 <font color="#ff0000">직교</font> (고유벡터의 내적 = 0) → 서로 <font color="#ff0000">상관 없음</font>
- <font color="#ff0000">고유값의 합 = 변수의 개수</font> (표준화 자료의 전체 분산)
- 주성분의 설명력(분산 비율) = λᵢ ÷ 변수 개수
- 고유벡터는 길이 1로 정규화 → 계수에 1/√2 등이 붙음, 부호가 반대여도 같은 축

**2변수 (상관계수 r) 공식**
- 표준화한 두 변수 A, B의 상관계수가 0.1이다. 상관행렬을 이용해 주성분분석을 할 때 마지막(제2) 주성분으로 적절한 것은?
- 상관행렬 $[1, r](1,%20r.md)$의 고유값: <font color="#ff0000">1 + r, 1 − r</font>
- <mark style="background:#fff88f">r > 0</mark>이면
	- 제1 주성분 = (A + B)/√2 (고유값 1 + r)
	- <mark style="background:#fff88f"><strong><font color="#ff0000">제2 주성분 = (A − B)/√2 (고유값 1 − r)</font></strong></mark>
- r < 0이면 두 주성분이 서로 바뀜
	- 제1 주성분 = (A − B)/√2 (고유값 1 − r)
	- 제2 주성분 = (A + B)/√2 (고유값 1 + r)
- 예) r = 0.1 → 고유값 1.1, 0.9 → 제2 주성분 (A − B)/√2, 설명력 0.9 ÷ 2 = 45%

	- <mark style="background:#fff88f"><strong><font color="#ff0000">전체 분산(분산에 사용된 원래 변수의 개수) = 주성분의 분산(표준편차의 제곱) ÷ 전체 분산 중 주성분이 차지하는 비율</font></strong></mark>

#### <mark style="background:#fff88f">스크리플롯(Screeplot)</mark>
- 주성분의 개수를 선택하는데 도움이 되는 그래프 (x축 주성분 개수, y축 분산변화)
- <strong><mark style="background:#fff88f"><font color="#ff0000">수평을 이루기 바로 전 단계 개수로 선택</font></mark></strong>
![Pasted image 20261030214718.png](/assets/images/Pasted%20image%2020261030214718.png)
- 기울기가 3-4 구간에서 완만해지므로 <font color="#ff0000">주성분 개수는 2개로 선택</font>
- <font color="#245bdb">주성분 개수의 선택은 절대적인 것은 없으며, 연구자의 판단 (3개로 선택도 가능)</font>

#### <mark style="background:#fff88f"><strong><font color="#ff0000">다차원 척도법</font></strong></mark> (MDS : Multi-Dimensional Scaling)
- 데이터 간 <font color="#ff0000">거리</font> 정보의 근접성을 보존하는 방식으로 차원 축소하여 시각화
- 개체 간의 유사성/비유사성을 거리로 측정하여 2차원 또는 3차원 공간에 점으로 배치에 관계를 시각화
- 특징 : 데이터 축소 목적, <font color="#ff0000">Stress 값이 0에 가까울 수록 좋음, 글로벌 최적점 도달 어려움</font>
- 종류 : 계량적 MDS(<font color="#ff0000">양적척도(구간척도, 비율척도)</font> 활용), 비계량적 MDS(<font color="#ff0000">순서척도</font> 활용)

### 시계열 예측
#### 시계열 분석
- 시간의 흐름에 따라 관찰된 자료의 특성을 파악하여 미래를 예측 (주가데이터, 기온데이터)


#### 시계열 데이터의 변동 요인
- <u>추</u>세 요인 : <font color="#ff0000">장기적으로 증가, 감소하는 추세</font>
- <u>계</u>절 요인 : <font color="#ff0000">1년 이내에 고정 주기</font>로 반복되는 변동
- <u>순환</u> 요인 : 1년을 넘는<font color="#ff0000"> 중장기 파동</font>. 알려지지 않은 주기를 갖고 변화 (<font color="#ff0000">경제 전반, 특정 산업</font>)
- <u>불규칙</u> 요인 : <font color="#ff0000">위 3가지로 설명 불가한 요인</font>
  - <font color="#245bdb">'추운 계절의 순환이 불규칙하다.'</font>


#### <mark style="background:#fff88f"><strong><font color="#ff0000">정상성</font></strong></mark>
- 시계열 예측을 위해서는 모든 시점에 일정한 평균, 분산을 가지는 정상성을 만족해야 함
- <strong>정상성의 조건</strong>은 <mark style="background:#fff88f"><strong><font color="#ff0000">평균 일정, 분산 일정, 공분산은 시차에만 의존.</font></strong></mark>
	- 시차에만 의존한다 : 두 지점 사이의 관계가 얼마나 떨어져있는지로만 결정
	- 시점: t (예: 3일째, 10일째)
	- 시차: 두 시점의 간격 h (예: 3일째와 5일째면 시차 2)
	- 공분산: 시점 t의 값과 시점 t+h의 값이 얼마나 같이 움직이는지
- <mark style="background:#fff88f"><strong>정상 시계열도 시차에 따른 자기상관을 가질 수 있음.</strong></mark>
- 정상시계열로 변환 방법
	- <strong><mark style="background:#fff88f"><font color="#ff0000">차분</font></mark></strong> : 현 시점의 자료를 이전 값으로 빼서 <mark style="background:#fff88f"><strong><font color="#ff0000">평균을 일정하게</font></strong></mark> 만드는 방법
		- 1차 차분 : Zₜ − Zₜ₋₁ → 추세 제거
		- <font color="#ff0000">계절 차분</font> : 계절 주기(s)만큼 떨어진 값과의 차이 Zₜ − Zₜ₋ₛ → <font color="#ff0000">계절성 제거</font>
		- 월별 자료(주기 12)면 Zₜ − Zₜ₋₁₂, 분기별 자료(주기 4)면 Zₜ − Zₜ₋₄
		- 추세와 계절성이 모두 있으면 일반 차분과 계절 차분을 함께 적용
	- <strong><mark style="background:#fff88f"><font color="#ff0000">변환</font></mark></strong> : <mark style="background:#fff88f"><strong><font color="#ff0000">로그변환</font></strong></mark>, <strong>제곱근변환, Box-Cox 변환</strong> 등으로 <mark style="background:#fff88f"><strong><font color="#ff0000">분산을 안정화</font></strong></mark>

#### 평활화
- 평활화는 불규칙 변동을 완화하는 효과가 있지만, 그것만으로 정상성이 보장되지는 않는다.
- 이동평균법 : 일정 기간의 평균
- 지수평활법 : 최근 시간 데이터에 가중치를 부여

#### <mark style="background:#fff88f">백색 잡음</mark>
- 시계열 모형의 잔차가 가져야 할 이상적인 형태로, 잔차가 백색잡음이면 모형이 정보를 충분히 추출했다고 본다.
- 시계열 모형의 오차항을 의미 (<strong><mark style="background:#fff88f">평균 및 분산 일정, 자기상관 없음</mark></strong>, <strong><mark style="background:#fff88f"><font color="#ff0000">정상성 만족</font></mark></strong>)
- 평균이 0이면 가우시안 백색잡음


#### <mark style="background:#fff88f"><strong><font color="#ff0000">시계열 모형</font></strong></mark>
- <mark style="background:#fff88f"><strong><font color="#ff0000">AR, MA, ARMA 모형</font></strong></mark>은 평균과 분산이 일정하고 공분산이 시차에만 의존하는 <mark style="background:#fff88f"><strong><font color="#ff0000">정상 시계열을 전제</font></strong></mark>로 한다. <strong>비정상 시계열은 차분이나 변환으로 정상화한 뒤 적용</strong>한다.

##### <mark style="background:#fff88f"><strong><font color="#ff0000">자기회귀(AR) 모형</font></strong></mark>
- 자기자신의 과거 값이 미래를 결정하는 모형
- 과거 관측값들의 선형결합
- 부분자기상관함수(<strong><mark style="background:#fff88f"><font color="#ff0000">PACF</font></mark></strong>)를 활용하여 p+1 시점부터 급격 감소하면 AR(p) 모형 선정
	- PACF → AR(p) → p시차까지 유의, p+1부터 유의한 막대 없음
- 자기회귀 모형은 현재 값 Zₜ를 자기 자신의 과거 값 Zₜ₋₁, Zₜ₋₂와 백색잡음 aₜ로 나타낸다
- Zₜ = φ₁Zₜ₋₁ + φ₂Zₜ₋₂ + aₜ
- Zₜ는 시점 t의 관측값, aₜ는 백색잡음, φ와 θ는 모수


##### <mark style="background:#fff88f"><strong><font color="#ff0000"> 이동평균(MA) 모형</font></strong></mark>
- 이전 백색잡음들의 선형결합으로 표현되는 모형
- 현재 값을 <mark style="background:#fff88f"><strong><font color="#ff0000">현재와 과거 시점의 백색잡음(오차항)의 선형결합</font></strong></mark>으로 나타낸다. 
- MA(q)는 Zₜ = aₜ − θ₁aₜ₋₁ − … − θq·aₜ₋q 형태
- MA 모형은 유한 개의 백색잡음 결합이므로 항상 정상성을 만족한다.
- 자기상관함수(<strong><mark style="background:#fff88f"><font color="#ff0000">ACF</font></mark></strong>)를 활용하여 q+1 시점부터 급격히 감소하면 MA(q) 모형 선정
	- ACF → MA(q) → q시차까지 유의, q+1부터 유의한 막대 없음


##### <mark style="background:#fff88f"><strong><font color="#ff0000">자기회귀누적이동평균(ARIMA) 모형</font></strong></mark>
- AR 모형과 MA 모형의 결합
- 비정상 시계열은 <mark style="background:#fff88f"><strong><font color="#ff0000">먼저 차분</font></strong></mark> 후 ARMA를 적용
- 시계열 데이터의 <strong>과거 관측값(AR)과 오차(MA)를 이용해 <mark style="background:#fff88f">미래를 예측</mark>하는 통계모델</strong>
- 데이터를 정상 시계열로 변환하여 분석하므로 통계적 안정성이 높다.
- <font color="#ff0000">ARIMA(p, d, q)</font>
	- <mark style="background:#fff88f"><strong><font color="#ff0000">p는 자기회귀 차수, d는 차분차수, q는 이동평균 차수.</font></strong></mark>
	- <mark style="background:#fff88f"><strong><font color="#ff0000">p는 AR 모형</font></strong></mark>과 <mark style="background:#fff88f"><strong><font color="#ff0000">q는 MA 모형</font></strong></mark>이 관련 있는 차수
	- <font color="#ff0000">d는 정상화시에 차분 몇 번 했는지 의미</font>
	- d = 0 : ARMA 모델 / p = 0 : IMA 모델 / q = 0 : ARI 모델
- <font color="#245bdb">계절성이 있는 경우 SARIMA 사용을 고려</font>


##### ARIMA 모형 문제
![Pasted image 20261028000728.png](/assets/images/Pasted%20image%2020261028000728.png)
- ACF는 시차 1의 약 0.76에서 시작해 시차 6(약 0.25)까지 신뢰한계 밖에 머물며 서서히 줄어드는(지수적 감소) 모습이고, 
- PACF는 시차 1(약 0.76), 2(약 0.35), 3(약 −0.30)에서 신뢰한계 ±0.2를 벗어난 뒤 시차 4부터 0이 되어 한계 안에 머문다. 
- ACF가 점차 감소하고 PACF가 시차 3 이후 절단되므로 AR(3), 즉 ARMA(3, 0)이 적절하다.

### 데이터 마이닝
- 방대한 데이터 속에서 새로운 <font color="#ff0000">규칙, 패턴을 찾고</font> 예측을 수행하는 분야
- 목표 정의 → 데이터 수집 및 이해 → <mark style="background:#fff88f"><strong><font color="#ff0000">데이터 전처리 → 데이터 마이닝 기법 적용</font></strong></mark> → 평가 및 해석

#### 데이터 마이닝의 유형
- 지도학습 : 정답이 있는 데이터를 활용
	- 분류 : 인공신경망, 로지스틱 회귀분석, 나이브베이즈, 분류트리, KNN, SVM 등
	- 회귀 : 인공신경망, 선형회귀분석, 회귀트리 등
- 비지도학습 : 정답이 없는 데이터들 사이의 규칙을 파악
	- 군집분석, 연관규칙분석, 차원축소

#### 과대적합과 과소적합
- <font color="#ff0000">과대적합(=과적합)</font> : 모델이 지나치게 데이터를 학습하여 매우 복잡해진 모델 (<font color="#ff0000">높은 분산, 낮은 편향</font>)
- <font color="#ff0000">과소적합</font> : 데이터를 충분히 설명하지 못하는 단순한 모델 (<font color="#ff0000">낮은 분산, 높은 편향</font>)
- <font color="#245bdb">분산과 편향은 Trade-Off 관계</font>
![Pasted image 20261026215605.png](/assets/images/Pasted%20image%2020261026215605.png)

#### 범주 불균형(class imbalance)
- 한 범주의 관측치가 다른 범주보다 지나치게 적어, 모델이 다수 범주 위주로 학습하고 소수 범주를 제대로 분류하지 못하는 현상
- 불균형 데이터는 오버샘플링(SMOTE 등), 언더샘플링, 가중치 조정으로 보완하고 정확도 대신 재현율, F1 점수 등으로 평가한다.

#### 데이터 분할과 교차검증
- 과대적합과 과소적합을 방지하고, 데이터가 불균형한 문제를 해결하기 위해 사용
- 분할된 데이터 셋 종류
	- 훈련용 데이터(Training Set) : 모델을 학습하는데 활용. <font color="#ff0000">가중치 학습</font>에 사용.
	- <mark style="background:#fff88f"><strong><font color="#ff0000">검증용 데이터</font></strong></mark>(Validation Set) : 모델의 <mark style="background:#fff88f"><strong><font color="#ff0000">과대,과소 적합을 조정(튜닝)</font></strong></mark>하는데 활용. 하이퍼 파라미터 조정, 모델 선택, 과적합 점검에 쓰임.
	- 평가용 데이터(Test Set)
		- <font color="#ff0000">모델의 최종 성능을 평가</font>하는데 활용
		- 학습 과정에서 활용되지 않은 데이터
- 분할된 데이터의 학습 및 검증 방법
	- 홀드아웃 : 전체 데이터를 학습용과 검증용으로 한 번만 나누어 사용
	- K-fold 교차검증 : 데이터를 k개의 집단으로 구분하여 <font color="#ff0000">k-1개 학습, 나머지 1개로 검증</font>
	- LOOCV : <font color="#ff0000">1개의 데이터로만 검증</font> 나머지로 학습, 신뢰도가 높지만 연산량이 많음
	- 부트스트래핑 : 복원추출을 활용하여 데이터 셋을 생성, 데이터 부족, 불균형 문제 해소

### 분류분석
#### 로지스틱 회귀분석
- 종속변수가 <font color="#ff0000">범주형 데이터</font>를 대상으로 성공과 실패 2개의 집단을 분류하는 문제에 활용
- 로지스틱 회귀모형의 <mark style="background:#fff88f"><strong><font color="#ff0000">연결함수</font></strong></mark> : <mark style="background:#fff88f"><strong><font color="#ff0000">로짓함수 log(p/(1−p))</font></strong></mark>
- <font color="#ff0000">종속 변수인 로짓과 독립 변수는 서로 선형적 관계</font>

##### 로지스틱 회귀분석의 원리
- 오즈(Odds)
	- 성공할 확률과 실패할 확률의 비
	- 범주 A에 속할 확률을 범주 B에 속할 확률로 나눈 값
	- $\color{red}{Odds = P / (1 - P) = \text{성공확률} / \text{실패확률}}$
	- 로지스틱 회귀 $\log\left(\frac{p}{1-p}\right) = \beta_0 + \beta_1 x$ 에서 $x$가 1 증가하면 오즈($\frac{p}{1-p}$)는 $e^{\beta_1}$배가 된다.
- 로짓(logit)변환
	- 오즈에 자연로그(자연상수 $e$가 밑)를 취하여 선형 관계로 변환
	- $\log_e(\frac{P}{1-P}) = wx + \beta$ ($w > 0$ : 확률 증가)
- <mark style="background:#fff88f"><strong>시그모이드 함수</strong></mark>
	- 로짓 함수의 역함수를 통하여, 0~1사이 확률을 도출하는 함수
	- 입력층이 직접 출력층으로 연결되고 출력층의 노드가 1개인 인공신경망에서 시그모이드 함수를 사용하면 로지스틱 회귀 모형과 작동 원리가 동일해짐.
	- 회귀모형의 연결함수
	- $\color{red}{P = \frac{1}{1 + e^{-(wx+\beta)}}}$

##### 로지스틱 회귀분석의 검정
- 회귀계수 추정 : <font color="#ff0000">최대우도법</font>
- 모형전체 검정 : 우도비검정(카이제곱검정)

#### <mark style="background:#fff88f">KNN(K-Nearest Neighbors)</mark>
- <strong>지도 학습</strong>
- 거리 기반으로 이웃에 더 많은 데이터가 포함되어 있는 범주로 분류
- <mark style="background:#fff88f"><strong>새로운 관측치와 거리가 가까운 K개의 학습 데이터를 찾아 다수결로 범주를 정한다.</strong></mark>
- 단순하고 효율적이며, 훈련이 따로 필요 없는 <font color="#ff0000">Lazy Model</font>
- <font color="#ff0000">K에 따라 결과가 달라짐</font>

#### 나이브베이즈 분류
##### 베이즈 정리

#### 의사결정나무(Decision Tree)
- <font color="#ff0000">노드 내 동질성이 커지고, 노드 간 이질성이 커지는 방향</font>으로 분리하는 트리 구조 모델
- 특징
	- 화이트 박스 모델, <font color="#ff0000">높은 과적합</font> 위험
- ※ 과적합 방지 방안
	- <font color="#ff0000">정지규칙</font>
		- 분할해도 얻는 것이 충분하지 않으면 분리를 더 이상 수행하지 않고 나무의 성장을 멈춤
		- 노드에 속한 관측치 수가 미리 정한 최소 개수보다 적으면 분할을 멈춘다.
		- 나무의 깊이가 미리 정한 최대 깊이에 도달하면 분할을 멈춘다.
		- 추가로 분할해도 불순도 감소량이 기준에 미치지 못하면 분할을 멈춘다.
		- <mark style="background:#fff88f"><strong><font color="#ff0000">분할로 얻는 정보이득이 미리 정한 임계값보다 작으면 분할을 멈춘다.</font></strong></mark>
	- <font color="#ff0000">가지치기</font> : 일부 가지를 제거하여 과적합을 방지
- 의사결정나무에서 마디를 분리하는 기준
	- <strong>카이제곱 통계량</strong>의 p-value가 가장 작아지는 방향으로 분리
	- <strong>지니 지수</strong>가 작아지는 방향으로 분리
	- <strong>엔트로피 지수</strong>가 가장 작아지는 방향으로 분리
	- 분산 감소량이 가장 커지는 방향으로 분리

##### 지니지수 
- **불순도(Impurity)**: 하나의 그룹에 서로 다른 클래스의 데이터가 얼마나 섞여 있는지를 나타내는 지표. 낮을수록 데이터가 잘 구분됨. 지니 불순도, 엔트로피 등을 사용
- 분할은 불순도 감소가 큰 후보를 선택할 수 있다.
- 연속된 분할은 변수 간 상호작용을 표현할 수 있다.
- 지니지수는 노드의 불순도를 나타내는 지표이며,<mark style="background:#fff88f"><strong><font color="#ff0000"> 지니지수가 낮아질수록 불순도는 낮아진다.</font></strong></mark>
- 한 노드에 하나의 범주만 있으면 지니지수는 0이다.
- 분할 할 때는 자식 노드들의 지니지수(가중평균)가 가장 많이 줄어드는 기준을 선택한다.
- 지니 지수 = 1 − Σ pᵢ²이며, 범주가 2개일 때 최댓값은 두 범주가 반반일 때의 0.5이다.

##### <font color="#ff0000">노드 분할 방법</font>
- 분류(범주형)에서의 분할 방법
	- CHAID 알고리즘 : 카이제곱 통계량
	- CART 알고리즘 : <mark style="background:#fff88f"><strong><font color="#ff0000"><strong><font color="#ff0000">지니지수</font></strong></font></strong></mark> 활용 ( $\color{red}{1 - \sum P^2}$ )
	- C4.5/C5.0 알고리즘 : <mark style="background:#fff88f"><font color="#ff0000">엔트로피지수</font></mark> 활용 ( $\color{red}{-\sum P(\log_2 P)}$ )

- 회귀(연속형)에서의 분할 방법
	- CHAID 알고리즘 : ANOVA, F-통계량
	- CART 알고리즘 : 분산감소량

- 지니지수와 엔트로피지수 계산
	- 앞면 확률 = $\frac{3}{5}$, 뒷면 확률 = $\frac{2}{5}$
	- 지니지수 : $\color{red}{1 - \left(\frac{3}{5}\right)^2 - \left(\frac{2}{5}\right)^2 = \frac{12}{25}}$
	- 엔트로피지수 : $-\frac{3}{5}\log_2\left(\frac{3}{5}\right) - \frac{2}{5}\log_2\left(\frac{2}{5}\right)$


#### <mark style="background:#fff88f"><strong><font color="#ff0000">서포트벡터머신(SVM)</font></strong></mark>
- <mark style="background:#fff88f"><strong><font color="#ff0000">마진이 최대가 되는 초평면</font></strong></mark>을 찾아 선형이나 비선형 <font color="#ff0000">이진 분류</font>, 회귀에서 활용 가능한 다목적 모델
- 구성요소
	- 하이퍼플레인(초평면) : 데이터를 구분하는 기준이 되는 경계, <font color="#ff0000">가중치벡터와 편향으로 결정</font>
	- <font color="#ff0000">서포트벡터 </font>
		- 클래스를 나누는 하이퍼플레인과 가까운 위치의 샘플
		- <font color="#ff0000">결정경계와 마진을 정하는데 직접 기여하는 관측값</font>
	- 마진 : 하이퍼플레인과 서포트벡터 사이의 거리
	- <mark style="background:#fff88f"><strong><font color="#ff0000">커널함수</font></strong></mark> 
		- <mark style="background:#fff88f"><strong><font color="#ff0000">저차원 데이터를 고차원 데이터로 변경</font></strong></mark>하는 함수
		- 선형으로 분리되지 않는 데이터도 분류할 수 있음
- 유형
	- 하드마진분류 : 오류 비허용
	- 소프트마진분류 : 마진 내 어느 정도 오류 허용


#### <mark style="background:#fff88f"><strong><font color="#ff0000">앙상블</font></strong></mark>
- 여러 개의 예측 모형들을 조합하는 기법
- <mark style="background:#fff88f"><strong>결합하는 개별 모델들 사이의 상관성이 높을수록 앙상블 예측 정확도가 낮아진다.</strong></mark>

##### <mark style="background:#fff88f"><strong><font color="#ff0000">보팅(Voting)</font></strong></mark>
- <strong><mark style="background:#fff88f">각 모델 예측 결과 중 가장 많이 나온 결과를 최종 결과로 채택</mark></strong>
- 여러 모델의 예측을 결합하여 최종 예측을 결정
- **하드보팅(Hard Voting)**: 각 모델의 예측 클래스에 대해 **다수결**로 결정
- **소프트보팅(Soft Voting)**: 각 모델의 클래스별 **예측 확률을 평균**하여 최종 클래스 결정

##### <mark style="background:#fff88f"><strong><font color="#ff0000">배깅(Bagging)</font></strong></mark>
- 복원추출에 기반을 둔 <font color="#ff0000">붓스트랩(Bootstrap)</font>을 생성하여 모델을 학습 후에 보팅으로 결합
- <mark style="background:#fff88f"><strong>분산을 줄이는데 효과적</strong></mark>
- 복원추출을 무한히 반복할 때 특정 하나의 데이터가 선택되지 않을 확률 (OOB 활용)
- $\color{red}{\lim_{N \to \infty} \left(1 - \frac{1}{N}\right)^N = 36.8\%}$
- <strong>(1 − 1/d)^d</strong>

##### <font color="#ff0000">랜덤포레스트</font>
- <strong>배깅에 의사결정나무를 추가</strong>하는 기법
- <mark style="background:#fff88f"><strong><font color="#ff0000">여러 의사결정나무를 만들어 결합하는 앙상블 모형</font></strong></mark>
- <strong>분할할 때마다 설명변수 일부를 무작위로 골라 나무들 사이의 상관성을 낮춘다.</strong>
- <font color="#ff0000">편향은 높지만 분산이 감소(과적합에 강함), 블랙박스 모델</font>

##### <mark style="background:#fff88f"><strong><font color="#ff0000">부스팅(Boosting)</font></strong></mark>
- <font color="#ff0000">잘못된 분류 데이터</font>에 큰 가중치를 주는 방법, 이상치에 민감
- <mark style="background:#fff88f"><strong>편향을 줄이는데 효과적</strong></mark>
- <mark style="background:#fff88f"><strong>병렬처리 불가</strong></mark>
- 종류
	- **AdaBoost**
		- 이전 모델이 잘못 분류한 데이터(오분류 표본)에 더 큰 가중치를 부여
		- 잘못 분류한 관측값의 가중치를 높이는 것
	- **GBM**(Gradient Boosting Machine)
		- 이전 모델의 예측 잔차를 줄이는 방향으로 새로운 모델을 학습
		-  손실 함수의 음의 기울기(제곱오차 손실에서는 잔차)를 다음 모형이 학습
	- <strong>XGBoost</strong>(<font color="#ff0000">GBM보다 빠르고 규제 포함</font>) : **GBM을 개선**한 알고리즘. **정규화(규제)를 적용**하여 **과적합을 완화하고 학습 효율을 높임**
	- <strong> Light GBM</strong>(<font color="#ff0000">학습속도 개선</font>) : **대용량 데이터 학습에 효율적**인 부스팅 알고리즘. **학습 속도 개선.** leaf-wise 성장 전략을 사용할 수 있음.
		- **Leaf-wise 성장 전략** : 의사결정나무를 만들 때, **현재 리프 노드(잎 노드) 중 분할했을 때 손실이 가장 크게 감소하는 노드를 선택해 분할하는 방식**

##### 스태킹(Stacking)
-  **여러 모델의 예측 결과를** 메타 학습기(Meta Learner)의 **입력으로 사용하여 최종 예측** 수행 
	- 메타 학습기(Meta Learner) : 여러 모델의 예측 결과를 학습해 최종 예측을 수행하는 모델
- <font color="#245bdb">보팅, 배깅, 랜덤포레스트는 병렬처리가 가능하며, 부스팅은 병렬처리가 불가</font>

- 인간의 뉴런을 모방한 단층 퍼셉트론의 등장, <font color="#ff0000">XOR 문제(비선형문제)</font> 해결의 불가

##### 다층 퍼셉트론의 등장
- 입력층과 출력층 사이에 하나 이상의 은닉층을 삽입한 구조
- 활성함수의 사용 : 시그모이드 함수를 통한 비선형 문제 해결
- 인공신경망의 특징
	- 블랙박스 모델
	- 은닉층 수와 노드 수는 <font color="#ff0000">사용자가 직접 설정하는 하이퍼파라미터</font>
	- 은닉층 수가 많아지면 복잡한 문제 해결 가능하지만, <font color="#ff0000">과적합 위험 증가</font>
	- 은닉층 수가 적어지면 복잡한 패턴 학습 못해 <font color="#ff0000">과소적합 가능성</font>
	- 은닉층의 노드 수는 줄이고 은닉층 수는 늘렸을 때 나타나는 현상 : 기울기 소실 문제


##### 인공신경망 학습 방법
- 순전파(피드포워드) : 정보가 전방으로 전달
- <font color="#ff0000">역전파 알고리즘</font> : 가중치를 수정하여 <font color="#ff0000">손실함수</font>의 값을 줄임 (합성함수의 곱 활용)
- 경사하강법
	- 경사의 내리막길로 이동하여 오차가 최소가 되는 최적의 해를 찾는 기법 (편미분 활용)
- <font color="#ff0000">기울기 소실 문제</font>
	- 다수의 은닉층에서 <font color="#ff0000">시그모이드 함수 사용</font> 시, 학습이 제대로 되지 않는 문제


##### 활성함수와 손실함수
- 은닉층에서의 활성함수 : 인공신경망의 선형성을 극복
	- 시그모이드 함수 : 0 ~ 1 사이의 확률 값을 가지며, 로지스틱 회귀 분석과 유사
	- 하이퍼볼릭 탄젠트(Tanh) 함수 : <font color="#ff0000">-1 ~ 1 사이 값</font>, 시그모이드 함수의 기울기 소실문제를 지연
	- ReLU 함수 : <font color="#ff0000">기울기 소실문제를 극복</font>, $max(0, x)$
- 출력층에서의 활성함수
	- 시그모이드 함수 : 이진분류 모델, 0~1 사이 확률 ( $\color{red}{\sigma = \frac{1}{1+e^{-x}}}$ )
	- 소프트맥수 함수 : 다중분류 모델, <mark style="background:#fff88f">확률의 총합이 1</mark> ( $\color{red}{\sigma_{x_k} = \frac{e^{x_k}}{\sum e^{x_i}}}$ )
		- 클래스가 2개일 때는 시그모이드와 동일
- 손실함수 : 예측값과 실제값의 차이를 측정하는 함수
	- MSE(Mean Square Error) : <font color="#ff0000">회귀</font> 모델
	- 크로스 엔트로피(Cross-Entropy) : <font color="#ff0000">분류</font> 모델

##### 평가지표
![Pasted image 20261026221304.png](/assets/images/Pasted%20image%2020261026221304.png)
- 정밀도 : 양성 예측 중 실제 양성의 비율
- 민감도(재현율) : 실제 양성 중 양성으로 예측한 비율
- 특이도 :  실제 음성 중 음성으로 예측한 비율
- 오분류율 = 1 - 정확도 = (FN + FP) / 전체
- 재현율(Recall)은 민감도(Sensitivity), TP Rate, Hit Rate라고도 함
- <font color="#ff0000">F-1 Score는 Precision과 Recall의 조화평균</font>
- Precision과 Recall은 Trade-Off 관계
- F-$\beta$ Score
	- $\beta > 1$ : 재현율(Recall)에 큰 비중
	  - $\beta < 1$ : 정밀도(Precision)에 큰 비중
	  - $\beta = 1$ : F-1 Score와 동일

#### <mark style="background:#fff88f"><strong><font color="#ff0000">거리 측정 방식</font></strong></mark>
##### 연속형 변수
![Pasted image 20261026222513.png](/assets/images/Pasted%20image%2020261026222513.png)
- <mark style="background:#fff88f"><strong><font color="#ff0000"> 유클리디안 거리</font></strong></mark>
	- 두 점 사이의 직선 거리
	- $d(x,y)=\sqrt{\sum_{i=1}^{n}(x_i-y_i)^2}$ 
 - <mark style="background:#fff88f"><strong><font color="#ff0000">맨하튼 거리</font></strong></mark>
	- **각 변수 차이의 절댓값을 합산**
	- 맨해튼 거리는 유클리디안 거리보다 항상 크거나 같다
	- <mark>$d(x,y)=\sum_{i=1}^{n}\vert x_i-y_i\vert$</mark>
	- 예) 3차원 맨허튼 거리
		- 점 $A=(1,2,3)$, 점 $B=(4,6,5)$
		- 각 좌표의 차이를 계산
		- x축: $\vert 1-4\vert=3$
		- y축: $\vert 2-6\vert=4$
		- z축: $\vert 3-5\vert=2$
		-  모두 더하기
		- $d(A,B)=\vert 1-4\vert+\vert 2-6\vert+\vert 3-5\vert$
- <strong>체비셰프거리</strong>
	 - 각 변수 차이의 <strong>절댓값 중 최댓값</strong>
	 - $d(x,y)=\max_i \vert x_i-y_i \vert$
- 민코우스키 거리
	- 유클리드, 맨하튼 거리, 체비쇼프 거리를 <font color="#ff0000">일반화</font>한 거리
	- $\color{red}d(x,y)=\left(\sum_{i=1}^{n}\vert x_i-y_i\vert^p\right)^{1/p}$
- <mark style="background:#fff88f"><strong><font color="#ff0000">마할라노비스 거리</font></strong></mark>
	- <mark style="background:#fff88f"><strong><font color="#ff0000">변수 간 상관관계</font></strong></mark>와 분산을 <mark style="background:#fff88f"><strong><font color="#ff0000">고려</font></strong></mark>한 거리
	- $d(x,y)=\sqrt{(x-y)^{\top} S^{-1}(x-y)}$
- 표준화 거리
	- 각 변수의 표준편차를 고려하여 계산하는 거리
	-  $d(x,y)=\sqrt{\sum_{i=1}^{n}\left(\frac{x_i-y_i}{s_i}\right)^2}$

##### 범주형 변수
- 자카드 유사도
	- 두 집합의 교집합 크기를 합집합 크기로 나눈 값
	- $J(A,B)=\frac{\vert A\cap B\vert}{\vert A\cup B\vert}$ 
- 코사인 유사도
	- 두 벡터가 이루는 각도의 코사인값으로 유사도를 측정
	- $\cos(x,y)=\frac{x\cdot y}{\Vert x\Vert\Vert y\Vert}$

##### 군집 간 거리 측정 방식
- 최단 연결법(=단일연결법) : 군집간 가장 가까운 데이터
- 최장 연결법(=완전연결법) : 군집간 가장 먼 데이터
- 평균 연결법 : 군집의 모든 데이터들의 평균
- 중심 연결법 : 두 군집의 중심
- <mark style="background:#fff88f"><strong><font color="#ff0000">와드 연결법</font></strong></mark> : 두 군집의 <mark style="background:#fff88f"><strong><font color="#ff0000">오차제곱합이 최소</font></strong></mark>가 되는 위치

#### K평균 군집화(K-means Clustering)
- **비계층 군집화** 방법으로 <font color="#ff0000">거리 기반</font>으로 데이터를 군집화하는 **비지도 학습** 알고리즘
- k-means는 레이블(반응변수) 없이 유사성으로 군집을 찾는 비지도 기법
	- 반응변수(종속변수): 예측하거나 설명하려는 변수
	- 레이블(Label): 데이터의 정답 또는 목표값
특징
- 군집 수 <font color="#ff0000">K를 사전에 지정</font>
- 각 군집에 속한 데이터들의 **평균을 중심점(Centroid)으로 사용**
- 각 데이터를 가장 가까운 중심점의 군집에 할당
- 군집 내 데이터와 중심점 사이의 제곱 거리 합(SSE)을 최소화하는 방향으로 반복 수행
	- SSE : 각 데이터와 자신이 속한 군집의 중심점 사이의 거리 제곱을 합한 값
- **중심점 갱신에 따라 데이터가 다른 군집으로 재할당될 수 있음**
- 한 번 군집에 속한 데이터<font color="#ff0000">는 중심점이 변경되면 군집이 변할 수 있음</font>
- **이상치와 초기 중심점 설정에 민감**
- 수치형 데이터에 적합하며, 변수의 스케일에 영향을 받음
- **과정**
1. 군집의 개수 K 설정 (<font color="#ff0000">Elbow Method 등을 활용</font>하여 적절한 K 선택)
	- **Elbow Method**
		- 군집 수 K에 따른 군집 내 오차 제곱합(SSE)의 변화를 확인하여 **적절한 K를 선택하는 방법**
		- **SSE가 급격히 감소하다가 감소 폭이 완만해지는 지점**을 적절한 K의 후보로 선택
2. K개의 초기 중심점 설정
3. 각 데이터를 가장 가까운 중심점의 군집에 할당
4. 각 군집에 속한 데이터들의 평균으로 중심점 갱신
5. 군집 할당이나 중심점이 수렴 조건을 만족할 때까지 3~4번 반복
- **K-menas의 변형**
	- **K-modes** : **범주형 데이터에 적합**하며, **중심점을 최빈값**(Mode)으로 갱신
	- **K-medoids** : 실제 데이터 중 **대표 객체(medoid)를 중심점으로 선정**하며, 일반적으로 **K-means보다 이상치에 강건**함
	- **K-means++** : 초기 중심점을 더 효과적으로 선택하여 초기화에 따른 문제를 완화하는 방법

#### <mark style="background:#fff88f"><strong><font color="#ff0000">DBSCAN</font></strong></mark>
- <mark style="background:#fff88f"><strong><font color="#ff0000">비계층적 군집화 방법</font></strong></mark>으로 <font color="#ff0000">밀도기반</font>
- 일정 반경(eps) 안에 최소 점 개수(MinPts) 이상이 모이는 밀도 높은 영역을 이어 군집을 만드는 밀도 기반 군집 방법
  
**특징**
- <strong><mark style="background:#fff88f"><font color="#ff0000">군집 수를 사전에 정하지 않아도 됨</font></mark></strong>
- <mark style="background:#fff88f"><strong>초기 중심값 설정이 불필요</strong></mark>
- 노이즈와 이상치에 강함
- Eps와 MinPts를 사전에 설정
- eps와 MinPts만 정하면 군집 수가 자동으로 결정
- 밀도가 낮은 영역의 점은 잡음(이상값)으로 처리할 수 있다.
- 초승달 모양처럼 <strong>구형이 아닌 군집도 찾아낼 수 있다.</strong>
- DBSCAN의 점은 핵심점(core), 경계점(border), 잡음점(noise) 세 가지로 구분
  

### 기타 비계층적 군집분석
- 퍼지군집화 : 확률 기반
	- 각 데이터가 특정 군집에 속할 <font color="#ff0000">확률</font>을 각각 계산해가며 군집화
- <mark style="background:#fff88f"><strong><font color="#ff0000">EM알고리즘</font></strong></mark> : 분포 기반
	- <strong><mark style="background:#fff88f">혼잡분포군집 모델에서 최대가능도추정을 보완하기 위해 사용되는 분석 기법</mark></strong>
	- 혼잡분포군집은 잠재변수가 있어 가능도를 직접 최대화하기 어려우므로 EM알고리즘으로 모수를 추정
	- <mark style="background:#fff88f"><strong>가우시안혼잡모델(GMM)은 EM 알고리즘을 사용하여 모델 매개변수를 추정하며 초기 중심값 설정에 따라 그 결과가 달라질 수 있다.</strong></mark>
	- Likelihood의 기댓값을 계산하는 <font color="#ff0000">E단계</font>와 기댓값 최대화 추정값을 계산하는 <font color="#ff0000">M단계 </font>반복
- <mark style="background:#fff88f"><strong><font color="#ff0000">자기조직화지도(SOM)</font></strong></mark> : 그래프 기반 -> 차원축소 + 인공신경망 + 군집화
	- <mark style="background:#fff88f"><strong><font color="#ff0000">비지도 학습</font></strong></mark>으로 <mark style="background:#fff88f"><strong><font color="#ff0000">차원 축소와 군집화를 동시에 수행</font></strong></mark>
	- <strong><mark style="background:#fff88f">노드별 데이터 할당 수는 균등하지 않음.</mark></strong>
	- <font color="#ff0000">신경망을 활용</font>하여 차원축소를 통해 지도로 형상화하여 군집화하는 방법
	- <font color="#ff0000">완전연결</font>의 형태를 가지며, <font color="#ff0000">순전파 방식</font>만 사용
	- 각 노드가 승자가 되기 위한 <font color="#ff0000">경쟁 학습</font>
	- 경쟁 학습으로 승자 노드와 이웃 노드의 가중치를 갱신하며, 입력 공간의 위상(topology)을 보존하는 특징


#### 군집분석의 평가지표
- <font color="#ff0000">실루엣 계수</font>
	- $S(i) = \frac{b(i)-a(i)}{\max(a(i),b(i))}$ ($-1 \sim 1$)
	- $a(i)$ : i번째 데이터에서 자신이 속한 군집 내 다른 데이터 포인트 들과의 평균 거리
	- $b(i)$ : i번째 데이터에서 가장 가까운 다른 군집 내 다른 데이터 포인트 들과의 평균 거리
- WCSS (Within Clusters Sum of Squares)
	- $WCSS = \sum_{C_k}^{C_n} (\sum_{d_i \in C_k}^{d_m} \text{distance}(d_i, C_k)^2)$
	- C : 군집의 중심 값
	- d : 클러스터 내에 있는 데이터
- <font color="#ff0000">Elbow Method</font> : 최적의 군집 개수(K) 선택 방법
  ![Pasted image 20261026222640.png](/assets/images/Pasted%20image%2020261026222640.png)
- <mark style="background:#fff88f"><strong><font color="#ff0000">경사가 완만해지는 지점이 최적의 K 개수</font></strong></mark>

### 연관분석
- 항목들간의 조건-결과로 이루어지는 패턴(연관규칙)을 발견하는 기법 (<font color="#ff0000">장바구니 분석</font>)
- 특징
	- 결과가 단순하고 분명 (<font color="#ff0000">IF~THEN~</font>)
	- <font color="#ff0000">비목적성 분석기법</font>
	- 품목 수가 증가할수록 <font color="#ff0000">계산량이 기하급수적으로 증가</font>
	- <font color="#ff0000">비지도 학습</font>
	- <font color="#245bdb">연관 분석에 시간 개념을 추가하여 순차패턴분석을 수행</font>

##### 지지도 
- P(A⋂B)
- 전체 거래 중 A와 B 두 품목이 동시에 포함된 거래 비율

##### 신뢰도
- $P(B\mid A)$ = P(A⋂B) / P(A)
- A 품목이 거래도리 때 B 품목도 거래될 확률 (조건부 확률)
- 연관규칙 A → B의 방향을 B → A로 바꾸었을 때 신뢰도만 변함

##### 향상도
- P(A⋂B) / P(A)P(B)
- A 품목과 B 품목의 상관성
- (향상도 > 1 : 양의상관관계, <mark style="background:#fff88f"><strong><font color="#ff0000">향상도 = 1 : 상관없음</font></strong></mark>, 향상도 < 1 : 음의상관관계)


#### 빈발항목 도출 알고리즘
- <font color="#ff0000">Apriori 알고리즘</font>
	- 최소 지지도를 만족하는 빈발 항목을 추출하여 연관규칙분석의 연산량을 줄이는 기법
	- 절차 : 빈도수 집합 탐색 → 최소 지지도 확인 → 후보 집합 생성 → 반복 탐색 → 연관규칙 도출
- FP-Growth 알고리즘
	- Apriori 알고리즘의 반복 과정을 /트리 기반으로 대체하여 연산 효율 향상
