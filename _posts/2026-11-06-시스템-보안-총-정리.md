### 윈도우 서버 보안

#### etc/passwd 파일

- 예) root : <strong>x</strong> : 0 : 0 : root : /root: /bin/bash
- 사용자 계정 이름, <span style="background: #fff88f"><strong>패스워드 필드(실제 사용하지 않고 /etc/shadow에 저장)</strong></span>, UID, GID, 사용자 관련 기타 정보, 홈 디렉터리, 로그인 셸
- 패스워드 필드 : `!`나 `*`이면 로그인이 잠긴 계정이라는 뜻이고, 비어 있으면 패스워드 없이 로그인할 수 있는 위험한 상태
