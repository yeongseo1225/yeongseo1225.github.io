## 1. R기초와 데이터 마트
### 데이터 마트
#### <mark style="background:#fff88f">데이터 마트(DM)</mark>
- 특정 주제에 맞게 데이터를 모아 놓은 <mark style="background:#fff88f"><strong><font color="#ff0000">소규모 데이터 웨어하우스</font></strong></mark>
- 원천 데이터 수집 → 데이터 웨어하우스 → 데이터 마트
#### 요약변수와 파생변수
- **요약변수** : 수집된 정보를 종합한 변수로서 <font color="#ff0000">재활용성</font> 이 높음 (1개월간 수입)
- **파생변수** : 의미를 부여한 변수, <font color="#ff0000">논리적 타당성</font> 필요 (고객구매등급)
### 결측값 처리와 이상값 검색
#### EDA (탐색적 자료 분석)
- 데이터의 의미를 찾기 위해 <font color="#ff0000">통계, 시각화</font>를 통해 파악
- EDA의 4가지 주제
	- <u>저</u>항성의 강조 : 자료 변동에 민감하지 않음
	- <u>잔</u>차 계산 : 값들이 주경향으로부터 얼마나 벗어나 있는지 확인하는 척도
	- 자료변수의 <u>재</u>표현 : 원래 변수를 적정한 척도로 변환
	- 그래프를 통한 <u>현</u>시성 : 시각화를 통하여 효율적으로 파악
	- **<font color="#245bdb">'저잔재현'</font>
#### 결측값 처리
- 존재하지 않는 데이터, NULL/NA로 표시
##### 단순대치법
- **완전분석법** : 결측값 가지는 데이터 삭제
- **평균 대치법**
	- 비조건부 평균 대치법 : 단순 평균으로 대치
	- 조건부 평균 대치법 : 회귀분석의 결과로 대치
- **단순 확률 대치법** : 확률적으로 선택하여 대치
	- Hot-Deck : 현재 데이터 셋에서 비슷한 성향으로 대체
	- Cold-Deck : 유사한 외부 출처에서 비슷한 성향으로 대체
	- Nearest Neighbor : 바로 가까운 응답으로 대체
##### **다중 대치법**
  - 여러 번 대치하여 종합 (대치 → 분석 → 결합)
  - <font color="#245bdb">다중 대치법은 분산 과소 추정 문제 해결이 가능</font>

#### 이상값 검색
- 극단적으로 크거나 작은 값이며, 의미 있는 데이터일 수도 있음 (키 230cm)
- <font color="#ff0000">이상값을 항상 제거하는 것은 아님</font>
- 표본오차는 표본 평균의 변동성을 나타내는 지표이지 개별 관측치의 이상값 판정 기준이 아님
- **ESD(Extreme Studentized Deviation)**
	- 데이터가 정규분포를 따른다고 가정할 때, <mark style="background:#fff88f"><strong><font color="#ff0000">평균으로부터 표준편차의 3배 넘어가는 데이터는 이상값</font></strong></mark>으로 판단
	  ![Pasted image 20261025202930.png](/assets/images/Pasted%20image%2020261025202930.png)
- <mark ><mark style="background:#FFE868"></mark><strong><font color="#ff0000">사분위수</font></strong></mark>
  ![Pasted image 20261025203228.png](/assets/images/Pasted%20image%2020261025203228.png)
	- <mark style="background:#fff88f"><strong><font color="#ff0000">Q1 - 1.5IQR보다 작거나, Q3 + 1.5IQR보다 크면 이상값</font></strong></mark>으로 판단
	- 상한, 하한, 최솟값, 1~3사분위값, 최댓값 등을 표현하며, **평균값은 표현하지 않음**
	- <mark style="background:#fff88f"><strong><font color="#ff0000">사분위수 범위(IQR)는 전체 
	- 데이터의 50%가 분포하는 구간의 길이를 나타냄</font></strong></mark>
	- 상자 그림을 통해 데이터의 관측치 개수는 알 수 없음.
	![Pasted image 20261025203250.png](/assets/images/Pasted%20image%2020261025203250.png)
	- B의 데이터가 A보다 넓게 분포되어 있으므로, <font color="#ff0000">B의 분산이 A보다 크음</font>
	- Q2의 위치가 B가 더 높이 있으므로, <font color="#ff0000">B의 중앙값이 A보다 큼</font>
	- A에는 상한을 벗어나는 데이터가 존재하므로, <font color="#ff0000">A에는 이상치가 존재한다고 판단 가능</font>
	- <mark><font color="#ff0000"><strong>A와 B의 평균은 알 수 없음</strong></font></mark>
- **Z-Score**
	- 데이터를 표준화(평균 0, 표준편차 1) 후, 일정 임계 값을 초과할 경우 이상값으로 판단
- **DBScan**
	- 밀도를 이용하여 밀도가 적은 부분의 데이터를 이상값으로 판단

## 2. 통계분석
### 통계학 개론
#### 자료의 척도 구분
- 질적 척도
	- 명목척도 : 어느 집단에 속하는지 나타내는 자료 (대학교, 성별)
	- 순서척도(서열척도) : 서열관계가 존재하는 자료 (학년, 순위)
- 양적 척도
	- 등간척도(구간척도) : 구간 사이 간격이 의미가 있으며 덧셈과 뺄셈만 가능 (온도, 지수 등)
	- 비율척도 : <font color="#ff0000">절대적 기준 0</font>이 존재하고 사칙연산 가능, <font color="#ff0000">가장 많이 수집되는 자료</font> (무게, 나이 등)
#### 기초 확률의 이해
- 사건 : 여러 반복된 시행을 통해 결과로서 나타나는 표본공간의 부분 집합
- 표본공간 : 통계적 실험에 의하여 일어날 수 있는 모든 가능한 결과
	- 예) 동전 두 개를 던질 때 표본공간 S= {(앞, 앞), (앞, 뒤), (뒤, 앞), (뒤, 뒤)}
- 확률 : 통계적 현상의 확실함을 나타내는 척도로 수학적 확률과 통계적 확률로 구분
- 확률의 덧셈 정리 : 두 사건 A, B 중 하나 이상 일어날 확률
	- P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
- 조건부 확률 : 특정 사건 B가 발생했을 때 A가 발생할 확률
	- P(A|B) = P(A ∩ B)/P(B) (백신을 맞았을 때 감기에 걸릴 확률)
- <font color="#ff0000">독립사건</font> : A, B가 서로 영향을 주지 않는 사건 ( <font color="#ff0000">P(A|B) = P(A)</font> )
	- P(A ∩ B) = P(A)P(B) (주사위 A가 3이 나왔을 때, 주사위 B가 3이 나올 확률)
- <font color="#ff0000">배반사건</font> : A, B가 서로 동시에 일어나지 않는 사건
	- P(A ∩ B) = ∅ (동전을 던졌을 때 앞면과 뒷면이 동시에 나올 확률)

#### 기초 통계의 이해
- 확률변수 : 표본공간의 각 원소에 해당하는 값(확률)을 대응하는 함수
	- 예) 주사위 던지는 눈의 수는 1~6까지이며, 이는 확률변수 $X$의 가능한 값
- 이산확률분포 : 0, 1, 2, 3 처럼 셀 수 있는 확률변수에 확률이 대응
  - 예) 주사위 눈 $X$에 대한 확률분포

| <center>$X$</center><center></center> | <center>1</center>   | <center>2</center>   | <center>3</center>   | <center>4</center>   | <center>5</center>   | <center>6</center>   |
| ------------------------------------- | -------------------- | -------------------- | -------------------- | -------------------- | -------------------- | -------------------- |
| <center>$P(X)$</center>               | <center>1/6</center> | <center>1/6</center> | <center>1/6</center> | <center>1/6</center> | <center>1/6</center> | <center>1/6</center> |

- 기댓값 : 장기적으로 기대되는 평균값, 확률분포의 무게중심
- 분산 : 각 값이 평균에서 얼마나 떨어져 있는지를 구한 값 ( $V(X) = E(X^2) - [E(X)]^2$ )
- <font color="#ff0000">이항분포</font> : 연속된 $n$번의 독립적 시행에서 각 시행 확률 $p$를 가질 때의 이산확률분포
	- 이항분포의 평균 : $\mu = np$ , 이항분포의 분산 : $\sigma^2 = np(1 - p)$
- <font color="#ff0000">정규분포</font> : 자연 현상이나 통계 데이터에서 자주 나타나는 대표적인 연속확률분포 ($\color{red}{N(\mu, \sigma^2)}$)
- <font color="#ff0000">표준정규분포</font> : 정규분포 중에서도 평균이 0, 표준편차가 1인 특별한 분포
	- $\color{red}{Z = \frac{X-\mu}{\sigma} \sim N(0,1)}$

### 기초 통계분석
#### <font color="#ff0000">기초 통계량</font>
##### 중심경향성 측면
- 평균 : 모든 값을 더한 후 데이터 개수로 나눈 값
- 중앙값 : 데이터를 크기 순서로 나열했을 때 중간에 위치한 값
- 최빈값 : 데이터에서 가장 자주 나타나는 값

##### 분산 정도 측면
- 범위 : 최댓값에서 최솟값을 뺀 값이며, <font color="#ff0000">이상치에 민감</font>
- 분산 : 각 데이터가 평균과 얼마나 떨어져 있는지 나타내는 지표
- 표준편차 : 분산에 제곱근을 취한 값, 원래 단위와 같아 해석이 용이
- 사분위수(IQR) : 데이터의 상위 75%와 하위 25%의 중간 범위
- <font color="#ff0000">변동계수(CV)</font> : 표준편차에서 평균을 나눈 백분율, 단위 다른 변수간 상대적 비교에 유용

##### 관계 측면
- <font color="#ff0000">공분산</font> : 두 확률변수의 상관정도
	- $공분산 = 0$ : 상관이 전혀 없는 상태
	- $공분산 > 0$ : 양의 상관관계
	- $공분산 < 0$ : 음의 상관관계
	- <font color="#ff0000">최소, 최대값이 없어</font> 강약 판단 불가
- <font color="#ff0000">상관계수</font> : 공분산의 단위와 범위 영향을 <font color="#ff0000">표준화</font>하여, 상관정도를 $-1 \sim 1$값으로 표현
	- $상관계수 = 1$ : 정비례 관계
	- $상관계수 = 0$ : 상관없음
	- $상관계수 = -1$ : 반비례 관계
	- 공분산과 독립성의 관계
	- 두 변수가 독립이면 <font color="#ff0000">공분산은 0이지만, 공분산이 0이라고 두 변수가 독립이라고 할 수는 없음</font>
#### 첨도와 왜도
##### 첨도
![Pasted image 20261025210254.png](/assets/images/Pasted%20image%2020261025210254.png)
- 자료의 분포가 얼마나 뾰족한 지 나타내는 척도
- 첨도 = 3 : 정규 분포 형태
	- <font color="#245bdb">3을 빼서 0을 기준으로 정규분포 형태를 판단하기도 함</font>
- 값이 클수록 뾰족한 모양

##### 왜도
![Pasted image 20261025210049.png](/assets/images/Pasted%20image%2020261025210049.png)
- 자료 분포의 비대칭 정도 ($0$일 때 대칭)
- $\color{red}{왜도 < 0 : 최빈값 > 중앙값 > 평균값}$
- $\color{red}{왜도 > 0 : 최빈값 < 중앙값 < 평균값}$
- <font color="#245bdb"> 평균값은 꼬리를 따라감</font>

#### 추론통계
- 일부 표본의 데이터를 바탕으로 모집단을 추정하거나 가설을 검정하는 통계 기법
- 모집단 → 표본추출 → 표본집단 → 모집단 예측(추정, 가설검정)

#### 표본추출 방법
- 랜덤 추출법 : 무작위로 표본 추출
- 계통 추출법 : 번호 부여하여 일정 간격으로 추출
- <mark><font color="#ff0000">집락 추출법</font></mark>(=군집 추출법)
	- 여러 군집으로 나눈 뒤 군집을 선택하여 랜덤 추출
	- **군집 내 이질적 특징, 군집 간 동질적 특징**
	- 예) 아파트 
- <mark><font color="#ff0000">층화 추출법</font></mark>
	- **군집 내 동질적 특징, 군집 간 이질적 특징**
	- 같은 비율로 추출 시, 비례 층화 추출법
	- 예) 학년 추출
- 복원, 비복원 추출
	- 복원 추출 : 추출되었던 데이터를 <font color="#ff0000">다시 포함시켜</font> 표본 추출
	- 비복원 추출 : 추출되었던 데이터를 제외하고 표본 추출

#### 확률분포
- 확률 변수의 개별 값들이 가지는 확률 값의 분포

##### 이산 확률분포
![Pasted image 20261025211517.png](/assets/images/Pasted%20image%2020261025211517.png)
- 값을 셀 수 있는 분포, 확률질량함수로 표현
- 베르<u>누</u>이분포 : 결과가 두 가지 중 한가지로 나타나는 베르누이시행으로 나타나는 분포
	- 예) 동전 던지기, 시험의 합격/불합격
- 이항분<u>포</u> : $N$번의 베르누이시행 중 $K$번 성공할 확률의 분포
	- 예) 동전을 20번 던져 앞면이 나오는 횟수
- 기하분<u>포</u> : 성공확률이 $p$인 베르누이시행에서 처음으로 성공할 때까지 시행횟수의 분포
	- 예) 동전을 던져 처음으로 앞면이 나오기까지 던진 횟수
- 음이<u>항</u>분포 : 성공확률이 $p$인 베르누이시행을 $r$번 성공할 때까지 반복 시행횟수의 분포
	- 예) 동전을 던져 앞면이 5번 나오기까지 던진 횟수
- 초기<u>하</u>분포 : $N$개 중 비복원추출로 $n$번 추출했을 때 원하는 결과가 $k$번 나올 확률의 분포
	- 예) 10개 구슬 중 4개의 구슬이 당첨 구슬일 때, 4번 뽑았을 때 당첨 구슬을 2번 뽑을 확률
- 다<u>항</u>분포 : $N$번 시행에서 각 시행이 여러 개의 결과를 가질 수 있는 확률 분포
	- 예) 주사위를 20번 던져 각 면이 나오는 횟수
- <u>포</u>아송분포 : 단위 시간 내 발생할 수 있는 사건의 발생 횟수에 대한 분포
	- 예) 하루동안 발생하는 출생자 수, 한 시간 동안 사무실에 걸려온 전화의 수
- <font color="#245bdb">'누포항하'</font>

##### 연속 확률분포
- 값을 셀 수 없는 분포, 확률밀도함수로 표현
- 균일분포 : 모든 값 동일한 확률
- <font color="#ff0000">정규분포</font> : 우리가 일상생활에서 흔히 보는 확률변수의 평균 분포를 근사한 분포
	- 예) 사람들의 키 혹은 IQ 점수의 분포, 시험 성적의 분포
- <font color="#ff0000">t분포</font> : 정규분포와 유사하지만, 꼬리 부분이 더 두껍고 긴 분포
	- (T검정 활용) <font color="#ff0000">표본이 30개 보다 작은 집단</font>에 대한 평균 검정
- 카이제곱분포 : 독립적인 정규분포를 따르는 변수들의 제곱합으로 구성된 분포
	- (카이제곱 검정 활용) 두 집단의 동질성 검정, 단일 집단의 모분산 검정
- F분포 : 두 개의 서로 다른 카이제곱 분포의 비율
	- (F검정 활용) 두 집단의 분산 동질성 검정
- 지수분포 : 사건 간 시간 간격 분포
- 감마분포 : 지수분포의 일반화
- 베타분포 : 두 모수 $\alpha, \beta$에 대한 0~1사이 비율 분포

#### 표본평균의 표본분포
- 표본평균의 기댓값 : $E(\bar{X}) = \mu$
- 표본평균의 분산 : $V(\bar{X}) = \frac{\sigma^2}{n}$
- 표본평균의 표준편차 $= \sigma_{\bar{X}} = \frac{\sigma}{\sqrt{n}}$ (=표준오차)
- 표본평균의 표준화 : $Z = \frac{\bar{X}-\mu}{\frac{\sigma}{\sqrt{n}}} \sim N(0,1)$
- ($\mu$ : 모집단의 평균, $\sigma$ : 모집단의 표준편차, $\bar{X}$ : 표본평균, $n$ : 표본의 크기)

#### 점추정
- 모집단이 특정한 값으로 추정하며, <font color="#ff0000">추정량(Estimator)으로 모수를 추정</font>
- 추정량의 조건
	- <u>불</u>편성(Unbiasedness) : 추정량의 기댓값이 실제 모수와 같음 (<font color="#ff0000">편향이 0이 되는 경우</font>)
	- <u>효</u>율성(Efficiency) : 여러 추정량 중 분산이 작은 것이 더 효율적인 추정량
	- <u>일</u>치성(Consistency) : 표본 크기가 증가할수록 추정량이 모수에 가까워짐
	- <u>충</u>족성(Sufficiency) : 추정량이 모집단의 정보를 최대한 반영
	- <font color="#245bdb">'불효일충'</font>
- 대표적인 추정량
	- 모집단의 평균 $\mu \rightarrow$ 표본평균 $\bar{X} = \frac{1}{n}\sum X$
	- 모집단의 분산 $\sigma^2 \rightarrow$ 표본분산 $s^2 = \frac{1}{n-1}\sum(X - \bar{X})^2$

#### <mark style="background:#fff88f"><strong><font color="#ff0000">구간추정</font></strong></mark>
- <mark style="background:#fff88f"><strong><font color="#ff0000">일정한 신뢰 수준 하에서 모수가 포함될 것으로 기대되는 범위를 정하여 모수를 추정</font></strong></mark>
- 모집단이 특정한 구간으로 추정 (95%, 99%를 가장 많이 사용)
- 모집단의 분산을 알고 있는 경우
	- $\bar{X} - Z_{\frac{\alpha}{2}}\frac{\sigma}{\sqrt{n}} \le \mu \le \bar{X} + Z_{\frac{\alpha}{2}}\frac{\sigma}{\sqrt{n}}$
	- 신뢰수준 95% : $Z_{\frac{\alpha}{2}} = 1.960$
	- 신뢰수준 99% : $Z_{\frac{\alpha}{2}} = 2.576$
- 모집단의 분산을 모르는 경우
	- <font color="#ff0000">자유도가 n-1인 t분포</font>를 이용하여 신뢰구간을 추정
	- $\bar{X} - t_{\frac{\alpha}{2}, n-1}\frac{S}{\sqrt{n}} \le \mu \le \bar{X} + t_{\frac{\alpha}{2}, n-1}\frac{S}{\sqrt{n}}$ ($S$ : 표본표준편차)

#### 가설검정
![Pasted image 20261025212549.png](/assets/images/Pasted%20image%2020261025212549.png)
- <mark style="background:#fff88f"><strong><font color="#ff0000">검정통계량</font></strong></mark>(Test Statistic)
	- 표본 데이터를 이용하여 계산하며, 귀무가설의 기각 여부를 판단하는 기준이 되는 통계량
	- 검정 통계량이 표본으로부터 하나의 값으로 산출되는 것은 맞지만, 그 값 자체로 기각 여부를 판단하는 것이 아니라 귀무가설 하의 분포(p-value)와 비교하여 판단한다.
	  - Z검정 : Z통계량
	  - t검정 : t통계량
	  - 카이제곱 검정 : χ² 통계량
	  - 분산분석(ANOVA) : F통계량
- 모집단의 특성에 대한 주장을 가설로 세우고 표본조사로 가설의 채택여부를 판정
- 귀무가설($H_0$) : 일반적으로 생각하는 가설 (차이가 없다)
- 대립가설($H_1$) : 귀무가설을 기각하는 가설, <font color="#ff0000">증명하고자 하는 가설</font> (차이가 있다, 크다/작다)
- <mark style="background:#fff88f"><strong><font color="#ff0000">유의수준</font></strong></mark>($\color{red}\alpha$) : 귀무가설이 참일 때 기각하는 <font color="#ff0000">1종 오류</font>를 범할 확률의 허용 한계 (일반적 0.05)
- 유의확률(p-value) : 귀무가설을 지지하는 정도를 나타내는 확률

#### 가설 검정 R결과 해석
- 귀무가설 / 대립가설 설정
	- ‘차이가 없다’ 혹은 ‘동일하다’ → 귀무가설
- 양측 혹은 단측검정 확인
	- 대립가설의 값이 ‘같지 않다’ → 양측검정 / ‘값이 크다’, ‘값이 작다’ → 단측검정
- 일표본 혹은 이표본 확인
	- 하나의 모집단 → 일표본 / 두개의 모집단 → 이표본
- 귀무가설 기각 혹은 채택
	- $p\text{-value} < \text{유의수준}(\alpha)$ → 귀무가설 기각
	- $p\text{-value} > \text{유의수준}(\alpha)$ → 귀무가설 채택
- t검정인 경우 - 단일표본, 대응표본, 독립표본 확인
	- 모집단에 대한 평균검정 → 단일표본
	- 동일 모집단에 대한 평균비교 검정 → 대응표본
	- 서로 다른 모집단에 대한 평균비교 검정 → 독립표본

#### 모수 검정
- 모집단이 특정한 분포(보통 정규분포)를 따른다고 가정하고 수행하는 가설검정

- 귀무가설/대립가설 설정
	- ‘차이가 없다’ 혹은 ‘동일하다’ → 귀무가설로 설정
	- : <font color="#ff0000">두 학교의 성적은 동일하다</font>
- 양측 혹은 단측검정 확인
	- alternative hypothesis = 대랍 가설
	- not equal to 0 -> 대립 가설 값이 같지 않다
	- 대립가설의 값이 같지 않다 → <font color="#ff0000">양측검정</font>
- 일표본 혹은 이표본 확인
	- 두개의 모집단 → <font color="#ff0000">이표본</font>
- 귀무가설 기각 혹은 채택
	- conf.level = 0.95 -> a = 0.05
	- $p\text{-value} : 0.5515 > \text{유의수준}(\alpha) : 0.05 \rightarrow$ <font color="#ff0000">귀무가설 채택</font>
- 단일표본, 대응표본, 독립표본 확인
	- 서로 다른 모집단에 대한 평균비교 검정 → <font color="#ff0000">독립표본</font>
	- <font color="#245bdb">독립표본 t-검정은 두 집단의 분산이 같다는 가정(등분산 가정)이 전제가 되며, 등분산을 가정하지 않는 경우 welch의 t-검정을 사용</font>

#### 회귀분석
- 개념 : 독립변수들이 종속변수에 영향을 미치는지 파악하는 분석방법
	- 독립변수 : 원인을 나타내는 변수 ($x$)
	- 종속변수 : 결과를 나타내는 변수 ($y$)
	- 잔차(오차) : 계산값과 예측값의 차이
	- <font color="#245bdb">회귀분석은 독립변수와 종속변수간의 상관관계를 분석하는 방법이며, 인과관계를 보장하지 않음</font>
- 회귀계수 추정방법
	- <font color="#ff0000">최소제곱법(=최소자승법)</font> : 잔차의 제곱합(SSE)이 최소가 되는 회귀계수와 절편을 구하는 방법
- 회귀모형 평가
	- <font color="#ff0000">R-square</font> : 총 변동 중에서 회귀모형에 의하여 설명되는 변동이 차지하는 비율 (<font color="#ff0000">0 ~ 1</font>)

#### SST, SSE, SSR
![Pasted image 20261025213913.png](/assets/images/Pasted%20image%2020261025213913.png)
- SST : 전체의 변동
- SSE : 모형에 의해 설명되지 않는 변동
- SSR : 모형에 의해 설명되는 변동
- $\color{red}{R^2 = SSR/SST = 1 - SSE/SST}$
- <font color="#245bdb">SST : Sum of Squares Total / SSR : Sum of Squares Regression / SSE : Sum of Squares Error</font>

#### 회귀분석 종류
- 단순회귀 : 1 개의 독립변수와 종속변수의 선형관계
- <font color="#ff0000">다중회귀</font> : 2 개 이상의 독립변수와 종속변수의 선형관계
- <font color="#ff0000">다항회귀</font> : 2 개 이상의 독립변수와 종속변수가 2 차 함수 이상의 관계
- <font color="#ff0000">규제항이 포함된 회귀</font>
	- 릿지회귀(L2 규제) : L2 규제항을 포함 - $\sum W^2$
	- 라쏘회귀(L1 규제) : L1 규제항을 포함 - $\sum |W|$
	- 엘라스틱넷 : L1 과 L2 를 동시에 규제
- <font color="#ff0000">교호항이 포함된 회귀</font> : 독립변수들의 <font color="#ff0000">교호작용</font>이 포함된 회귀 모형
	- 교호작용 : <font color="#ff0000">두 개 이상의 독립변수가 상호작용</font>을 하여, 종속변수에 영향을 미치는 경우

#### 선형회귀분석의 가정
- <u>선</u>형성 : 종속변수와 독립변수는 선형관계
- 등<u>분</u>산성 : 오차의 분산이 고르게 분포
- <u>정</u>규성 : 오차가 정규분포의 특성을 지님
- <u>독</u>립성 : 오차가 서로 독립
  - <font color="#245bdb">'선분정독'</font>

#### <mark>다중공선성 문제</mark>
- 독립변수들간 강한 상관관계가 나타나는 문제
- 진단 방법
	- 변수간 상관계수 절댓값이 0.8 이상이면 의심
	- <font color="#ff0000">VIF(분산팽창인수) 값이 10 이상</font>이면 다중공선성 존재한다고 판단 ( $VIF = \frac{1}{1-R^2}$ )
	- R(0~1) 커지면 VIF도 커짐
	- 조건수가 30 이상이면 의심
- 해결방안 : 독립변수 제거, 차원 축소, 변수 선택, 규제항이 포함된 회귀

#### 최적의 회귀 방정식 탐색 방법
- 전진선택법 : 변수를 하나씩 추가하면서 최적의 회귀방정식을 찾아내는 방법
- 후진제거법 : 변수를 하나씩 제거하면서 최적의 회귀방정식을 찾아내는 방법
- 단계별 선택법 : 전진선택법 + 후진제거법으로 변수를 추가할 때 벌점을 고려
	- AIC (아카이케 정보 기준) : 편향과 분산이 최적화 되는 지점 탐색, 자료가 많을수록 부정확
	- BIC (베이즈 정보 기준) : AIC를 보완했지만 AIC보다 큰 패널티를 가지는 단점
	- Mallow’s Cp : SSE(잔차 제곱합)을 활용한 판단
	- <font color="#245bdb">AIC와 BIC 모두 작을수록 좋음</font>

#### 회귀분석의 분산분석(ANOVA)표
![Pasted image 20261025214220.png](/assets/images/Pasted%20image%2020261025214220.png)
- ANOVA 검정 : 3개 이상의 그룹의 평균을 비교하는 검정 (<font color="#ff0000">회귀모형의 유의성 분석 시 활용</font>)
- <font color="#ff0000">전체 데이터 수 = 자유도 + 1</font>
- 결정계수(R-Square) = $SSR / SST$
- 수정된 결정계수 = $1 - (n - 1)(MSE / SST)$
- <font color="#245bdb">다중 회귀에서는 수정된 R-square 값을 일반적으로 사용</font>

#### 회귀 모형의 검정
- 독립변수와 종속변수 설정
- 회귀계수 값의 추정
- 모형이 통계적으로 유의미한가 : 모형에 대한 <font color="#ff0000">F 통계량, p-value</font>
	- 귀무가설 : ‘<font color="#ff0000">모든 회귀계수는 0 이다</font>’
- 회귀계수들이 유의미한가 : 회귀계수들의 <font color="#ff0000">t 통계량, p-value</font>
	- 각각의 회귀계수에 대한 귀무가설 : ‘<font color="#ff0000">회귀 계수는 0 이다</font>’
- 위 두 검정(F검정, t검정)의 귀무가설을 모두 기각하면 해당 모델을 활용
- 모형이 설명력을 갖는가 : <font color="#ff0000">결정계수(R square)</font> 값

### 시계열 예측
#### 시계열 분석
- 시간의 흐름에 따라 관찰된 자료의 특성을 파악하여 미래를 예측 (주가데이터, 기온데이터)

#### 시계열 데이터의 변동 요인
- <u>추</u>세 요인 : 장기적으로 증가, 감소하는 추세
- <u>계</u>절 요인 : 계절과 같이 고정된 주기에 따라 변화
- <u>순환</u> 요인 : 알려지지 않은 주기를 갖고 변화 (<font color="#ff0000">경제 전반, 특정 산업</font>)
- <u>불규칙</u> 요인 : 위 3가지로 설명 불가한 요인
  - <font color="#245bdb">'추운 계절의 순환이 불규칙하다.'</font>

#### <mark style="background:#fff88f"><strong><font color="#ff0000">정상성</font></strong></mark>
- 시계열 예측을 위해서는 <font color="#ff0000">모든 시점에 일정한 평균과 분산</font>을 가지는 정상성을 만족해야 함
- 정상시계열로 변환 방법
  - <font color="#ff0000">차분</font> : 현 시점의 자료를 이전 값으로 빼서 평균을 일정하게 만드는 방법
  - 변환 : 로그변환, 제곱근변환, Box-Cox 변환 등으로 분산을 안정화

#### 평활화
- 이동평균법 : 일정 기간의 평균
- 지수평활법 : 최근 시간 데이터에 가중치를 부여

#### 백색 잡음
- 시계열 모형의 오차항을 의미 (평균 및 분산 일정, 자기상관 없음, <font color="#ff0000">정상성 만족</font>)
- 평균이 0이면 가우시안 백색잡음

#### <mark style="background:#fff88f"><strong><font color="#ff0000">시계열 모형</font></strong></mark>
- 자기회귀(AR) 모형
	- 자기자신의 과거 값이 미래를 결정하는 모형
	- 부분자기상관함수(<font color="#ff0000">PACF</font>)를 활용하여 p+1 시점부터 급격 감소하면 AR(p) 모형 선정
- 이동평균(MA) 모형
	- 이전 백색잡음들의 선형결합으로 표현되는 모형
	- 자기상관함수(<font color="#ff0000">ACF</font>)를 활용하여 q+1 시점부터 급격히 감소하면 MA(q) 모형 선정
- 자기회귀누적이동평균(ARIMA) 모형
	- AR 모형과 MA 모형의 결합
	- <font color="#ff0000">ARIMA(p, d, q)</font>
	- p와 q는 AR 모형과 MA 모형이 관련 있는 차수
	- <font color="#ff0000">d는 정상화시에 차분 몇 번 했는지 의미</font>
	- d = 0 : ARMA 모델 / p = 0 : IMA 모델 / q = 0 : ARI 모델
	- <font color="#245bdb">계절성이 있는 경우 SARIMA 사용을 고려</font>

### 3. 정형 데이터 마이닝
#### 데이터 마이닝 개요

#### 데이터 마이닝
- 방대한 데이터 속에서 새로운 <font color="#ff0000">규칙, 패턴을 찾고</font> 예측을 수행하는 분야
- 목표 정의 → 데이터 수집 및 이해 → 데이터 전처리 → 데이터 마이닝 기법 적용 → 평가 및 해석

#### 데이터 마이닝의 유형
- 지도학습 : 정답이 있는 데이터를 활용
	- 분류 : 인공신경망, 로지스틱 회귀분석, 나이브베이즈, 분류트리, KNN, SVM 등
	- 회귀 : 인공신경망, 선형회귀분석, 회귀트리 등
- 비지도학습 : 정답이 없는 데이터들 사이의 규칙을 파악
	- 군집분석, 연관규칙분석, 차원축소

#### 과대적합과 과소적합
- <font color="#ff0000">과대적합(=과적합)</font> : 모델이 지나치게 데이터를 학습하여 매우 복잡해진 모델 (<font color="#ff0000">높은 분산, 낮은 편향</font>)
- <font color="#ff0000">과소적합</font> : 데이터를 충분히 설명하지 못하는 단순한 모델 (<font color="#ff0000">낮은 분산, 높은 편향</font>)
- <font color="#245bdb">분산과 편향은 Trade-Off 관계</font>
![Pasted image 20261026215605.png](/assets/images/Pasted%20image%2020261026215605.png)

#### 데이터 분할과 교차검증
- 과대적합과 과소적합을 방지하고, 데이터가 불균형한 문제를 해결하기 위해 사용
- 분할된 데이터 셋 종류
  - 훈련용(Training Set) : 모델을 학습하는데 활용
  - 검증용(Validation Set) : 모델의 과대,과소 적합을 <font color="#ff0000">조정(튜닝)</font>하는데 활용
  - 평가용(Test Set) : <font color="#ff0000">모델을 평가</font>하는데 활용
- 분할된 데이터의 학습 및 검증 방법
  - 홀드아웃 : 전체 데이터를 학습용과 검증용으로 한 번만 나누어 사용
  - K-fold 교차검증 : 데이터를 k개의 집단으로 구분하여 <font color="#ff0000">k-1개 학습, 나머지 1개로 검증</font>
  - LOOCV : <font color="#ff0000">1개의 데이터로만 검증</font> 나머지로 학습, 신뢰도가 높지만 연산량이 많음
  - 부트스트래핑 : 복원추출을 활용하여 데이터 셋을 생성, 데이터 부족, 불균형 문제 해소

### 분류분석
#### 로지스틱 회귀분석
- 종속변수가 <font color="#ff0000">범주형 데이터</font>를 대상으로 성공과 실패 2개의 집단을 분류하는 문제에 활용

##### 로지스틱 회귀분석의 원리
- 오즈(Odds)
  - 성공할 확률과 실패할 확률의 비
  - $\color{red}{Odds = P / (1 - P) = \text{성공확률} / \text{실패확률}}$
- 로짓(logit)변환
  - 오즈에 자연로그(자연상수 $e$가 밑)를 취하여 선형 관계로 변환
  - $\log_e(\frac{P}{1-P}) = wx + \beta$ ($w > 0$ : 확률 증가)
- 시그모이드 함수
  - 로짓 함수의 역함수를 통하여, 0~1사이 확률을 도출하는 함수
  - $\color{red}{P = \frac{1}{1 + e^{-(wx+\beta)}}}$

##### 로지스틱 회귀분석의 검정
- 회귀계수 추정 : <font color="#ff0000">최대우도법</font>
- 모형전체 검정 : 우도비검정(카이제곱검정)

#### KNN(K-Nearest Neighbors)
- 거리 기반으로 이웃에 더 많은 데이터가 포함되어 있는 범주로 분류
- 단순하고 효율적이며, 훈련이 따로 필요 없는 <font color="#ff0000">Lazy Model</font>
- <font color="#ff0000">K에 따라 결과가 달라짐</font>

#### 나이브베이즈 분류
##### 베이즈 정리
- $P(A|B) = \frac{P(B|A)P(A)}{P(B)} = \frac{P(A \cap B)}{P(B)}$ ($P(A|B)$: 사후확률, $P(B|A)$: 우도, $P(A)$: 사전확률, $P(B)$: 주변우도)
![Pasted image 20261026220226.png](/assets/images/Pasted%20image%2020261026220226.png)
- <font color="#245bdb">과거의 경험을 활용하는 귀납적인 추론 방법</font>

##### 나이브베이즈 분류
- <font color="#ff0000">나이브(독립) + 베이즈 정리</font>를 기반으로 계산을 단순화하여 범주에 속할 확률 계산
- 서로 독립이라는 가정이 필요

#### 의사결정나무(Decision Tree)
- <font color="#ff0000">노드 내 동질성이 커지고, 노드 간 이질성이 커지는 방향</font>으로 분리하는 트리 구조 모델
- 특징
- 화이트 박스 모델, <font color="#ff0000">높은 과적합</font> 위험
- ※ 과적합 방지 방안
	- <font color="#ff0000">정지규칙</font> : 분리를 더 이상 수행하지 않고 나무의 성장을 멈춤
	- <font color="#ff0000">가지치기</font> : 일부 가지를 제거하여 과적합을 방지
- ##### <font color="#ff0000">노드 분할 방법</font>
- 분류(범주형)에서의 분할 방법
	- CHAID 알고리즘 : 카이제곱 통계량
	- CART 알고리즘 : <mark style="background:#fff88f"><strong><font color="#ff0000"><strong><font color="#ff0000">지니지수</font></strong></font></strong></mark> 활용 ( $\color{red}{1 - \sum P^2}$ )
	- C4.5/C5.0 알고리즘 : <font color="#ff0000">엔트로피지수</font> 활용 ( $\color{red}{-\sum P(\log_2 P)}$ )
- 회귀(연속형)에서의 분할 방법
	- CHAID 알고리즘 : ANOVA, F-통계량
	- CART 알고리즘 : 분산감소량

- 지니지수와 엔트로피지수 계산
	- 앞면 확률 = $\frac{3}{5}$, 뒷면 확률 = $\frac{2}{5}$
	- 지니지수 : $\color{red}{1 - \left(\frac{3}{5}\right)^2 - \left(\frac{2}{5}\right)^2 = \frac{12}{25}}$
	- 엔트로피지수 : $-\frac{3}{5}\log_2\left(\frac{3}{5}\right) - \frac{2}{5}\log_2\left(\frac{2}{5}\right)$

#### 서포트벡터머신(SVM)
- 마진이 최대가 되는 초평면을 찾아 선형이나 비선형 <font color="#ff0000">이진 분류</font>, 회귀에서 활용 가능한 다목적 모델
- 구성요소
	- 하이퍼플레인(초평면) : 데이터를 구분하는 기준이 되는 경계, <font color="#ff0000">가중치벡터와 편향으로 결정</font>
	- 서포트벡터 : 클래스를 나누는 하이퍼플레인과 가까운 위치의 샘플
	- 마진 : 하이퍼플레인과 서포트벡터 사이의 거리
	- <mark style="background:#fff88f"><strong><font color="#ff0000">커널함수</font></strong></mark> : 저차원 데이터를 고차원 데이터로 변경하는 함수
- 유형
	- 하드마진분류 : 오류 비허용
	- 소프트마진분류 : 마진 내 어느 정도 오류 허용

#### <mark style="background:#fff88f"><strong><font color="#ff0000">앙상블</font></strong></mark>
- 여러 개의 예측 모형들을 조합하는 기법
- 보팅(Voting) : 다수결 방식으로 최종 모델을 선택
	- 하드보팅 : 예측값을 다수결 투표
	- 소프트보팅 : 각 확률값의 평균으로 최종결과 사용
- 배깅(Bagging)
	- 복원추출에 기반을 둔 <font color="#ff0000">붓스트랩(Bootstrap)</font>을 생성하여 모델을 학습 후에 보팅으로 결합
	- 복원추출을 무한히 반복할 때 특정 하나의 데이터가 선택되지 않을 확률 (OOB 활용)
	- $\color{red}{\lim_{N \to \infty} \left(1 - \frac{1}{N}\right)^N = 36.8\%}$
	- ※ <font color="#ff0000">랜덤포레스트</font> : 배깅에 의사결정나무를 추가하는 기법
	- <font color="#ff0000">편향은 높지만 분산이 감소(과적합에 강함), 블랙박스 모델</font>
- 부스팅(Boosting)
	- <font color="#ff0000">잘못된 분류 데이터</font>에 큰 가중치를 주는 방법, 이상치에 민감
	- 종류 : AdaBoost, GBM, XGBoost(<font color="#ff0000">GBM보다 빠르고 규제 포함</font>), Light GBM(<font color="#ff0000">학습속도 개선</font>)
- 스태킹(Stacking)
	- 각각의 모델에서 학습한 예측 결과를 메타 학습기를 활용하여 다시 학습
	- <font color="#245bdb">보팅, 배깅, 랜덤포레스트는 병렬처리가 가능하며, 부스팅은 병렬처리가 불가</font>

	- 크로스 엔트로피(Cross-Entropy) : <font color="#ff0000">분류</font> 모델

#### <mark style="background:#fff88f"><strong><font color="#ff0000">거리 측정 방식</font></strong></mark>
##### 연속형 변수
![Pasted image 20261026222513.png](/assets/images/Pasted%20image%2020261026222513.png)
- 유클리디안 거리
	- 두 점 사이의 직선 거리
	- $d(x,y)=\sqrt{\sum_{i=1}^{n}(x_i-y_i)^2}$ 
- <mark ><mark style="background:#FFE868"></mark><strong><font color="#ff0000">맨하튼 거리</font></strong></mark>
	- **각 변수 차이의 절댓값을 합산**
	- <mark>$d(x,y)=\sum_{i=1}^{n}|x_i-y_i|$</mark>
	- 예) 3차원 맨허튼 거리
		- 점 $A=(1,2,3)$, 점 $B=(4,6,5)$
		- 각 좌표의 차이를 계산
		- x축: $|1-4|=3$
		- y축: $|2-6|=4$
		- z축: $|3-5|=2$
		-  모두 더하기
		- $d(A,B)=|1-4|+|2-6|+|3-5|$
- 체비셰프거리
	 - 각 변수 차이의 절댓값 중 최댓값
	 - $d(x,y)=\max_i|x_i-y_i|$
- 민코우스키 거리
	- 유클리드, 맨하튼 거리, 체비쇼프 거리를 <font color="#ff0000">일반화</font>한 거리
	- $\color{red}d(x,y)=\left(\sum_{i=1}^{n}|x_i-y_i|^p\right)^{1/p}$ 
- 마할라노비스 거리
	- 변수 간 <font color="#ff0000">상관관계</font>와 분산을 <font color="#ff0000">고려</font>한 거리
	- $d(x,y)=\sqrt{(x-y)^T S^{-1}(x-y)}$
- 표준화 거리
	- 각 변수의 표준편차를 고려하여 계산하는 거리
	-  $d(x,y)=\sqrt{\sum_{i=1}^{n}\left(\frac{x_i-y_i}{s_i}\right)^2}$
##### 범주형 변수
- 자카드 유사도
	- 두 집합의 교집합 크기를 합집합 크기로 나눈 값
	- $J(A,B)=\frac{|A\cap B|}{|A\cup B|}$ 
- 코사인 유사도
	- 두 벡터가 이루는 각도의 코사인값으로 유사도를 측정
	- ${cos}(x,y)=\frac{x\cdot y}{\|x\|\|y\|}$

##### 군집 간 거리 측정 방식
- 최단 연결법(=단일연결법) : 군집간 가장 가까운 데이터
- 최장 연결법(=완전연결법) : 군집간 가장 먼 데이터
- 평균 연결법 : 군집의 모든 데이터들의 평균
- 중심 연결법 : 두 군집의 중심
- 와드 연결법 : 두 군집의 <font color="#ff0000">편차제곱합</font>이 최소가 되는 위치
#### K평균 군집화(K-means Clustering)
- **비계층 군집화** 방법으로 <font color="#ff0000">거리 기반</font>으로 데이터를 군집화하는 **비지도 학습** 알고리즘
특징
- 군집 수 <font color="#ff0000">K를 사전에 지정</font>
- 각 군집에 속한 데이터들의 **평균을 중심점(Centroid)으로 사용**
- 각 데이터를 가장 가까운 중심점의 군집에 할당
- 군집 내 데이터와 중심점 사이의 제곱 거리 합(SSE)을 최소화하는 방향으로 반복 수행
	- SSE : 각 데이터와 자신이 속한 군집의 중심점 사이의 거리 제곱을 합한 값
- **중심점 갱신에 따라 데이터가 다른 군집으로 재할당될 수 있음**
- 한 번 군집에 속한 데이터<font color="#ff0000">는 중심점이 변경되면 군집이 변할 수 있음</font>
- **이상치와 초기 중심점 설정에 민감**
- 수치형 데이터에 적합하며, 변수의 스케일에 영향을 받음
**과정**
1. 군집의 개수 K 설정 (<font color="#ff0000">Elbow Method 등을 활용</font>하여 적절한 K 선택)
	- **Elbow Method**
		- 군집 수 K에 따른 군집 내 오차 제곱합(SSE)의 변화를 확인하여 **적절한 K를 선택하는 방법**
		- **SSE가 급격히 감소하다가 감소 폭이 완만해지는 지점**을 적절한 K의 후보로 선택
2. K개의 초기 중심점 설정
3. 각 데이터를 가장 가까운 중심점의 군집에 할당
4. 각 군집에 속한 데이터들의 평균으로 중심점 갱신
5. 군집 할당이나 중심점이 수렴 조건을 만족할 때까지 3~4번 반복
  
**K-menas의 변형**
- **K-modes** : **범주형 데이터에 적합**하며, **중심점을 최빈값**(Mode)으로 갱신
- **K-medoids** : 실제 데이터 중 **대표 객체(medoid)를 중심점으로 선정**하며, 일반적으로 **K-means보다 이상치에 강건**함
- **K-means++** : 초기 중심점을 더 효과적으로 선택하여 초기화에 따른 문제를 완화하는 방법

### 기타 비계층적 군집분석
- 퍼지군집화 : 확률 기반
	- 각 데이터가 특정 군집에 속할 <font color="#ff0000">확률</font>을 각각 계산해가며 군집화
- EM알고리즘 : 분포 기반
	- Likelihood의 기댓값을 계산하는 <font color="#ff0000">E단계</font>와 기댓값 최대화 추정값을 계산하는 <font color="#ff0000">M단계 </font>반복
- <mark style="background:#fff88f"><strong><font color="#ff0000">자기조직화지도(SOM)</font></strong></mark> : 그래프 기반 -> 차원축소 + 인공신경망 + 군집화
	- <font color="#ff0000">신경망을 활용</font>하여 차원축소를 통해 지도로 형상화하여 군집화하는 방법
	- <font color="#ff0000">완전연결</font>의 형태를 가지며, <font color="#ff0000">순전파 방식</font>만 사용
	- 각 노드가 승자가 되기 위한 <font color="#ff0000">경쟁 학습</font>

#### 군집분석의 평가지표
- <font color="#ff0000">실루엣 계수</font>
	- $S(i) = \frac{b(i)-a(i)}{\max(a(i),b(i))}$ ($-1 \sim 1$)
	- $a(i)$ : i번째 데이터에서 자신이 속한 군집 내 다른 데이터 포인트 들과의 평균 거리
	- $b(i)$ : i번째 데이터에서 가장 가까운 다른 군집 내 다른 데이터 포인트 들과의 평균 거리
- WCSS (Within Clusters Sum of Squares)
	- $WCSS = \sum_{C_k}^{C_n} (\sum_{d_i \in C_k}^{d_m} \text{distance}(d_i, C_k)^2)$
	- C : 군집의 중심 값
	- d : 클러스터 내에 있는 데이터
- <font color="#ff0000">Elbow Method</font> : 최적의 군집 개수(K) 선택 방법
  ![Pasted image 20261026222640.png](/assets/images/Pasted%20image%2020261026222640.png)
- 경사가 완만해지는 지점이 최적의 K 개수
- <font color="#245bdb">같은 군집간에는 응집도가 높고, 다른 군집간에는 응집도가 낮아야 좋은 모델</font>

### 연관분석
#### 연관분석
- 항목들간의 조건-결과로 이루어지는 패턴을 발견하는 기법 (<font color="#ff0000">장바구니 분석</font>)
- 특징
	- 결과가 단순하고 분명 (IF~THEN~)
	- <font color="#ff0000">비목적성 분석기법</font>
	- 품목 수가 증가할수록 <font color="#ff0000">계산량이 기하급수적으로 증가</font>
	- <font color="#245bdb">연관 분석에 시간 개념을 추가하여 순차패턴분석을 수행</font>

#### 연관분석의 지표
- 지지도 : $\frac{N(A \cap B)}{\text{전체}} = P(A \cap B)$
	- A와 B 두 품목이 동시에 포함된 거래 비율
- 신뢰도 : $\frac{P(A \cap B)}{P(A)}$
	- A 품목이 거래 될 때 B품목도 거래될 확률 (<font color="#ff0000">조건부 확률</font>)
- 향상도 : $\frac{P(A \cap B)}{P(A)P(B)}$
	- A 품목과 B 품목의 상관성
	(향상도 > 1 : 양의상관관계, 향상도 = 1 : 상관없음, 향상도 < 1 : 음의상관관계)
- <font color="#245bdb">'지신향'</font>

#### 빈발항목 도출 알고리즘
