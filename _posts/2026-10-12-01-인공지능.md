## 회귀분석
- 수치형 데이터(Numerical Data) :숫자로 나타내며, 수치의 크기나 연산이 의미 있는 데이터.
	- 이산형 데이터 :셀 수 있는 데이터 (예: 학생 수, 자동차 대수)
	- 연속형 데이터 :연속적인 값을 가질 수 있는 데이터 (예: 키, 몸무게, 시간)
- 범주형 데이터(Categorical Data) :데이터를 특정한 종류나 집단으로 구분하여 나타낸 데이터.
	- 명목형 데이터
		- 순서가 없는 데이터 
		- 예) 혈액형(A형, B형, O형, AB형), 거주 지역(서울,부산,대구)
	- 순서형 데이터
		- 순서나 등급이 있는 데이터
		- 예) 만족도(불만족 < 보통 < 만족), 성적 등급(A< B <C)
- 숫자로 표현 했다고 해서 반드시 수치형 데이터인 것은 아님. 예를 들어 혈액형을 A형=1, B형=2, O형=3, AB형=4로 표현하더라도 숫자 4가 숫자 1보다 크다는 의미는 없음. 
  단순히 범주를 구분하기 위한 번호일 뿐.
### 로지스틱 회귀분석
- 종속변수가 **범주형**(주로 0과 1)일 때, **어떤 사건이 일어날 확률을 예측**하는 **분류 모형**.
	- 범주형 데이터(Categorical Data) : 데이터를 특정한 종류나 집단으로 구분하여 나타낸 데이터.

#### (1) 로지스틱 회귀분석의 원리
로짓 함수와 시그모이드 함수는 서로 역함수
- **오즈(Odds)** 
	- 성공할 확률을 실패할 확률로 나눈 값
	- Odds = $\frac{p}{1-p}=\frac{\text{성공 확률}}{\text{실패 확률}}$ 
- **로짓(logit)**
	- 오즈에 자연로그를 취한 값
	- $[ \ln\left(\frac{p}{1-p}\right)=z=\beta_0+\beta_1x_1+\cdots+\beta_nx_n]$
	- 출력값 : <mark>**실수 전체 $(-\infty, +\infty)$**</mark> 
- **시그모이드 함수**
	- 로짓 함수의 역함수로 로짓 값을 **0과 1 사이의 확률로 변환**하는 함수
	- $p=\frac{1}{1+e^{-z}}$
#### (2) 로지스틱 회귀분석의 검정 및 모형 선택을 위한 기본 개념
1. **우도와 모형의 종류**
	- **우도**(likelihood) : 관측된 데이터가 주어졌을 때 **모형이 데이터를 얼마나 그럴듯하게 설명하는지** 나타내는 값
	- **최대우도** : 모형의 계수를 바꿔 가며 우도가 가장 커지도록 조정했을 때(최대우도추정) 얻는 우도의 최댓값
	- **축소모형** : **변수가 적은** 모형
	- **확장모형** : **변수가 많은** 모형
	- **포화모형** : **관측된 데이터를 완벽하게 설명하도록 모수를 설정한 모형**으로, 현재 데이터에 대한 적합도를 더 높일 수 없는 모형
2. **적합도**
	- **적합도** : **모형이 실제 관측 데이터를 얼마나 잘 설명**하는지를 나타내는 정도. (우도가 클수록 높음)
3. <mark>**이탈도(Deviance)**</mark>
	- 현재 모형이 포화모형에서 얼마나 벗어나 있는지를 나타내는 값. 
		- $D = -2\ln\left(\frac{L(\text{적합})}{L(\text{포화})}\right) \quad\text{(현재 모형 vs 포화모형)}$
		- **이탈도가 작을수록** 포화모형에 가까워 **적합도가 높고**
		- **이탈도가 클수록** 포화 모형과 차이가 커서 **적합도가 낮음**
	- 이탈도는 표본이 충분히 클 때 **카이제곱 분포**를 따르는 성질이 있어 **모형 적합도 검정과 모형 비교에 활용**됨.
	- **이탈도 종류**
		- 귀무 이탈도(Null Deviance) : 절편만 포함한 모형의 이탈도(독립변수 없음)
		- **잔차 이탈도**(Residual Deviance) : **독립변수를 포함**한 모형의 이탈도
		- 독립변수를 추가한 뒤 잔차 이탈도가 감소했다면, 독립변수를 포함한 모형이 데이터를 더 잘 설명하게 되었다고 볼 수 있음
4. **이탈도와 우도비 검정의 관계**
	- $[ G^2=D_{\text{귀무}}-D_{\text{잔차}} ]$
	- 귀무이탈도 − 잔차이탈도 = 독립변수를 추가해서 줄어든 이탈도 = 모형 전체 유의성 검정의 G²
	- 두 중첩 모형의 이탈도 차이를 카이제곱분포(자유도 = 추가된 독립변수 수)와 비교해, 독립변수를 추가한 것이 통계적으로 유의한지 검정할 수 있음
#### (3) 로지스틱 회귀분석의 검정 및 모형 선택
- **모형 유의성 검정 : 우도비 검정**
- **회귀계수 유의성 검정 : 왈드(Wald) 검정**
- **모형 적합도 평가 : 호스머-르메쇼 (Hosmer-Lemeshow) 검정**
- **모형 비교 :AIC**
##### 우도비 검정 : 모형 유의성 검정
- 두 모형의 우도를 비교하여 **모형의 유의성을 검정**하는 방법
	- 우도(likelihood) : 관측된 데이터가 주어졌을 때 **모형이 데이터를 얼마나 그럴듯하게 설명하는지** 나타내는 값.
- 로지스틱 회귀분석에서는 **독립변수를 포함한 모형이** 독립변수를 포함하지 않은 모형보다 **통계적으로 유의하게 개선되었는지 평가**
- **검정통계량:**
	- 변수가 많은 모형은 데이터에 더 잘 맞출 수 있으므로 항상 **L₁ ≥ L₀**. $G^2$로 이 차이가 **진짜 의미 있는 차이**인가, 아니면 **우연히 생긴 작은 차이**인지를 판단 -> 변수 추가로 얼마나 좋아졌는지를 계산
	- $G^2=-2\ln\left(\frac{L_0}{L_1}\right)$ 
	- $L_0$: 귀무가설에 해당하는 축소 모형의 최대우도
	- $L_1$: 대립가설에 해당하는 확장 모형의 최대우도
	- $\ln$: 자연로그
	- L₀/L₁은 0과 1 사이 값
		- 1에 가까움 → L₀ ≈ L₁ → 변수를 추가해도 설명력이 거의 안 늘었다
		- 0에 가까움 → L₀가 L₁보다 훨씬 작다 → 변수를 추가하니 설명력이 크게 늘었다
	- ln(1) = 0이고, 1보다 작은 수의 ln은 음수입니다. 앞에 −2를 곱하면 **항상 0 이상의 값**이 됩니다.
	- 따라서 **G²가 0에 가까우면** 변수 추가 효과가 없고, **G²가 크면 변수 추가 효과가 크다는 뜻**
- G²가 얼마나 커야 "큰 값"인지는 **카이제곱 분포**를 이용하여 검정. 
	- **자유도 = 추가된 독립변수의 개수**(두 모형의 모수 개수 차이)
- **귀무가설(H₀):**
	- 통계적 검정에서 차이, 효과 또는 관계가 없다고 가정하는 가설.
	- 추가된 독립변수의 회귀계수는 모두 0이다.
		- H₀: β₁ = 0, β₂ = 0(공부시간도 모의고사 점수도 합격과 관계없다)
		- H₁: β₁, β₂ 중 적어도 하나는 0이 아니다 (적어도 하나는 합격에 영향을 준다)
- p-value가 유의수준보다 작으면 귀무가설을 기각한다.
##### 왈드(wald) 검정 : 회귀계수 유의성 검정
- **개별 회귀계수의 유의성을 검정**하는 방법 추정한 계수가 0에서 표준오차 대비 얼마나 떨어져 있는지를 봄.
- 검정 통계량
- 표준정규분포 또는 카이제곱분포(자유도 1)
	- z = β̂ⱼ / SE(β̂ⱼ) → 표준정규분포
	- Wald χ² = z² → 자유도 1인 카이제곱분포
- 독립변수를 포함한 모형(확장모형) 하나만 적합하면 됨
- 가설
	- H₀: βⱼ = 0 (해당 독립변수는 종속변수와 관계없다)
	- H₁: βⱼ ≠ 0 (해당 독립변수는 유의한 영향을 준다)
- 해석
	- p-value < 유의수준(0.05) → H₀ 기각 → 해당 변수는 **유의한 변수**
	- p-value ≥ 유의수준 → H₀ 기각 불가 → 유의하지 않음

##### 호스머-르메쇼 검정(Hosmer-Lemeshow) 검정 : 모델 적합도 평가
- **로지스틱 회귀모형**의 예측 확률과 실제 관측 결과가 얼마나 일치하는지 평가하는 **적합도 검정**
- **카이제곱 분포**를 이용하여 검정
	- p-value가 클수록 모형의 적합도가 양호하다고 판단
	- p-value가 작으면 모형의 예측값과 실제 관측값 사이에 유의한 차이가 있다는 의미

##### AIC(Akaike Information Criterion, 아카이케 정보 기준) - 모형 비교 선택
- 통계 모형의 **적합도와 복잡도를 함께 고려**하여 **모형을 비교하고 선택하는 기준**
- 모형의 데이터 설명력이 높을수록 유리하지만, 모형이 복잡해질수록 페널티를 부여
- **AIC가 작을수록 적절한 모형**으로 판단
- 동일한 데이터에 적합한 여러 모형을 상대적으로 비교하는 데 사용
- 회귀분석, 로지스틱 회귀분석 등 다양한 통계 모형에 적용
- **공식:** $AIC=-2\ln(L)+2k$
	- **첫 번째 항:** 적합도 반영
	- **두 번째 항:** 모형의 복잡도에 대한 페널티
	- $L$: 모형의 최대우도(Maximum Likelihood)
	- $\ln(L)$: 최대우도의 자연로그
	- $k$: 모형에서 추정한 모수의 개수

## 인공신경망
**훈련**
- 가중치와 편향을 구하는 것
**가중치**
- 각 입력이 출력에 미치는 정도. 입력 신호의 중요도.
**편향**
- 노드가 얼마나 쉽게 활성화되는지를 조절하는 값
**가중합**
- 입력에 가중치를 곱해 더하고 편향을 더함 
**활성화 함수**
- 가중합을 변환해 다음 층에 전달하는 함수
**loss(손실)**
- **데이터 하나**에 대한 **오차**. 예: (예측값 − 정답)²
**cost(비용)** 
- **전체 데이터**(또는 배치)**의 loss**를 **평균** 낸 값
**비용 함수(손실 함수)** 
- 예측값과 실제값의 차이를 측정하는 함수
- 예측값 ŷ와 정답 y를 **비교해서** 오차 수치를 계산
**하이퍼파라미터(초매개변수)**
- 사람이 미리 설정하는 값. 훈련 전에 정하고 고정.
- 학습률, 배치크기, 에포크 수, 은닉층
**파라미터(매개변수)**
- 모델이 훈련을 통해 스스로 학습하는 값.
- 가중치, 편향
**기울기 소실 문제** 
- 오차역전파 알고리즘을 통해 업데이트 되는 가중치의 기울기가 사라지거나 소실되어 가중치가 업데이트 되지 않는 현상.
### 다층 퍼셉트론(Multilayer Perceptron, MLP)

![Pasted image 20261006223247](/assets/images/Pasted%20image%2020261006223247.png)
- 퍼셉트론 : 입력에 가중치를 곱해 더하고, 활성화 함수를 통과시켜 0 또는 1을 출력하는 가장 작은 신경망 단위.
- 단층 퍼셉트론의 한계 : 직선 하나로만 데이터를 나눌 수 있어서 **XOR 문제(비선형 문제)를 풀지 못함.**
  
- ##### **다층 퍼셉트론**
	- 입력층과 출력층 사이에 하나 이상의 **은닉층을 삽입**한 구조
	- **은닉층과 비선형 활성화 함수** 덕분에 **XOR 문제 같은 비선형 문제도 해결 가능**
	- **활성화 함수가 선형이거나 은닉층만 있는 경우 은닉층을 아무리 쌓아도 단층과 같다.** 
	- **역전파 + 경사하강법으로 학습**.
  
- ##### **인공신경망의 특징 (다층 퍼셉트론 기준)**
	- **블랙박스 모델**(입력과 출력은 확인할 수 있지만, 그 사이에서 왜 그런 결과가 나왔는지를 사람이 이해하기 어려움)
	- **은닉층 수와 노드 수**는 사용자가 직접 설정하는 **하이퍼파라미터**
	- **은닉층 수가 많아지면** 복잡한 문제 해결이 가능하지만, **과적합** 위험 증가
	- **은닉층 수가 적어지면** 복잡한 패턴 학습 못해 **과소적합** 가능성

- ##### 인공신경망 학습 방법
	순전파(예측) → 비용 함수(오차) → 역전파(기울기 계산) → 경사하강법(가중치·편향 갱신) → 반복	  
	1. **순전파**(Forward Propagation)
		- **입력 데이터를 입력층에서 출력층 방향으로 전달**하며, 각 층에서 **가중치·편향을 적용**하고 <mark>**활성화 함수를 통과**</mark>시켜 **최종 예측값(ŷ)을 계산**
	2. **비용함수(손실함수)**
		- **예측값 ŷ와 실제 값 y의 차이를 계산**
		- MSE(Mean Square Error) :회귀 모델
		- 이진 크로스엔트로피(Binary Cross-Entropy) : 이진 분류 모델
		- 크로스(교차) 엔트로피(Cross-Entropy) : 다중 분류 모델
	3. **역전파**(backward Propagation) 알고리즘
		- 출력층에서 입력층 방향으로 **오차를 전달**하며 각 가중치·편향의 **기울기 계산**(합성함수의 미분, 연쇄법칙 활용)
	4. **경사하강법**(Gradient Descent)
		- 역전파로 구한 기울기의 반대 방향으로 학습률만큼 가중치와 편향을 갱신하여 **손실이 최소가 되는 값을 찾음**(편미분 활용)
		- 학습률이 너무 작으면 수렴이 느리고, 너무 크면 바닥을 지나쳐 발산할 수 있음.
		- 경사하강법 문제
			- 학습률이 고정이라 평평한 구간에서는 느리고, 지역 최솟값에 갇힐 수 있음.
			- **평평한 구간(plateau)에서 느리다는 것**
				평평한 구간(기울기 ≈ 0)에서는 가중치 갱신량이 거의 0이라 학습이 매우 느려진다.
			- **지역 최솟값에 갇힐 수 있다는 것**
				- **지역 최솟값(local minimum)**: 손실 함수 전체에서 가장 작은 값은 아니지만, 주변에서만 가장 작은 지점.
				- 지역 최솟값에서는 기울기가 0이라 갱신이 멈추기 때문에, 전역 최솟값에 도달하지 못할 수 있음.
		- **경사하강법 개선 알고리즘**
			-  모멘텀 계열(방향 개선) :Momentum, Nesterov Momentum
			- 적응적 학습률 계열(학습률 조절) :AdaGrad, RMSProp, 
			- 둘다 합침 : Adam
			- **Momentum** : 관성(이전 갱신량을 유지하려는 성질)을 이용해 이전 이동 방향을 반영함. **기울기가 0이어도 이전 갱신량이 남아 있어 평평한 구간과 지역 최솟값을 빠져나올 수 있음**
			- **Nesterov Momentum(NAG)** : 모멘텀 개선. 이전 갱신량 만큼 먼저 이동한 위치에서 기울기 계산. 
			- **AdaGrad** : 많이 갱신된 가중치는 학습률을 줄이고, 적게 갱신된 가중치는 학습률을 키우는 방식으로 가중치마다 학습률을 다르게 적용함. 학습이 진행될수록 학습률이 계속 작아져 학습이 정체될 수 있음.
			- **RMSProp** : AdaGrad의 단점을 개선함. 과거 기울기 전체가 아니라 최근 기울기를 더 크게 반영해서 학습률이 0으로 사라지지 않게 함.
			- **Adam** : Momentum(방향 관성)과 RMSProp(학습률 조절)을 결합한 방식. 성능이 좋아 가장 널리 사용됨
		- **경사하강법 종류**
			- **배치경사하강법** : **전체 데이터**로 기울기를 계산해 갱신. 안정적이지만 느림
			- **확률적 경사하강법(SGD)** : **데이터 1개씩** 사용해 갱신. 빠르지만 불안정
			- **미니배치 경사하강법** : **데이터를 작은 묶음**으로 나눠 갱신. 배치와 SGD의 절충, 가장 많이 사용
		  
- ##### 비선형 활성화 함수
	- 은닉층에서의 활성화 함수
		- 시그모이드 함수 : **0 ~ 1 사이**의 확률 값. 기울기 소실 문제.
		- 하이퍼볼릭 탄젠트(Tanh) 함수 : **-1 ~ 1 사이**의 값, 시그모이드 함수의 기울기 소실 문제 지연.
		 - <mark>**ReLU 함수**</mark> : 기울기 소실 문제 완화. **max(0,z)**. 현재는 대부분 은닉층에서는 ReLu만 사용. **계산이 빠름**. Dying ReLU 문제 -> Leaky ReLU 등으로 보완
	 - 출력층에서의 활성화 함수
		 - **시그모이드** 함수 : **이진 분류** 모델의 출력층에 사용. **0~1 사이의 확률**. 로지스틱 함수와 유사( $\sigma(x)=\frac{1}{1+e^{-x}}$)
		 - **소프트맥스** 함수 : **다중분류** 모델의 출력층에 사용. **확률의 총합이 1($Softmax(z_i)=\frac{e^{z_i}}{\sum_j e^{z_j}}$ 
			 - 다중 분류의 출력층에서 각 클래스의 점수(z)를 **확률로 변환**하는 함수

	출력층 선택은 이진 분류면 시그모이드, 다중 분류면 소프트맥스, 회귀면 항등함수(값을 그대로 출력).
	
- ##### 인공신경망의 과적합 방지 방안
	1. 규제 
		- 라쏘(L1) 규제
			- 손실 함수에 **가중치 절댓값의 합**을 더해 과대적합을 방지
			- 중요하지 않은 특성의 가중치를 **정확히 0**으로 만듬.
		- 릿지(L2) 규제
			- 손실 함수에 **가중치 제곱의 합**을 더해 과대적합을 방지
			- 가중치를 **0에 가깝게 작게** 만들지만 **0은 거의 되지 않음**
	2. 드롭아웃(Dropout) : 일부 퍼셉트론을 비활성화시켜 학습
	3. 조기종료 : 특정 지점에서 학습을 미리 종료
	4. 모델의 복잡도 줄이기 : 은닉층의 퍼셉트론 수 감소
	5. 데이터 증강 : 데이터에 변형을 주어 데이터 수 증가
	6. 배치정규화 : 각 출력마다 정규화
- 벌점화 회귀
	- 과적합을 막기 위해 가중치(파라미터)의 크기에 벌점(패널티)를 부여하는 기법 
	- 라쏘(L1) 규제, 릿지(L2) 규제

**파라미터 수 공식**
- 한 층에 가중치와 편향이 몇 개 있는지 세는 공식
- (입력 노드 수 × 출력 노드 수) + 출력 노드 수(편향), 이것을 층마다 계산해 합산
	예) 입력 10개, 은닉층 5개 노드, 출력 1개 노드인 신경망의 총 파라미터 수는?
	- 입력 → 은닉: 10×5 + 5 = 55
	- 은닉 → 출력: 5×1 + 1 = 6
	- **총 61개**

## 딥러닝 분석

### DNN
- **은닉층이 2개 이상**으로 구성된 인공인경망(입력층 - 은닉층 - 출력층)
### CNN
- Convolution Layer와 Pooling Layer을 활용하여 <mark>**이미지에서 패턴</mark>을 찾는 신경망** 
1. 구조 : Input - Convolution Layer - Pooling Layer - Flatten - Fully Connected Layer
- Convolution Layer(합성곱 계층) : Convolution 연산을 통해 이미지의 특징을 추출(Filtering)
	- Convolution(합성곱): 필터를 이미지 위에서 이동시키며 각 영역과 연산하는 것
- Pooling Layer(풀링 계층) : 특징 맵의 공간적 크기를 줄여 연산량을 감소시키고, 주요 특징을 유지하는 계층.
- Flateen(평탄화) : 다차원 특징 맵(2차원, 3차원)을 1차원 벡터로 변환. 
- Fully Connected Later(완전 연결 계층) : DNN  구조를 가지며, 최종 출력 계층에서는 분류나 회귀를 수행할 수 있는 계층.
1. 주요모델
- 분류 : LeNet, AlexNet, VGG Nets, GoogLeNet, ResNet, EfficentNet
- 객체탐지 : RCNN, SPP Net, YOLO, Attention Net, EfficientDet
- 분할(세그멘테이션) : FCN, DeepLab, U-net, Segnet
### <mark>RNN</mark>
- <mark>**순차적인 데이터 학습**</mark>에 특화된 **순환구조**를 가지는 **신경망**
- <mark><strong>장기 의존성 문제</strong></mark>
	- 시퀀스가 길어질수록 **은닉층의 과거 정보가 현재 학습에 제대로 반영되지 않는 문제.**
	- 주요 원인 : 기울기 소실 문제
- **장기 의존성 극복 모델**
	- **LSTM** 
		- 장기 의존성 문제를 해결하기 위해 **셀 상태와 게이트를 이용해 장기 정보를 기억하고 불필요한 정보를 제거하는 RNN 모델**
		- 장기간의 시계열 데이터를 학습하는 데 적합
		- 셀 상태와 은닉 상태를 사용
		- <mark>**Forget Gate, Input Gate, Output Gate**</mark>
			- **망각 게이트(Forget Gate)**: 이전 정보 중 불필요한 정보를 제거
			- **입력 게이트(Input Gate)**: 새로운 정보 중 기억할 정보를 선택
			- **출력 게이트(Output Gate)**: 셀 상태를 바탕으로 출력할 정보를 결정
				- **셀 상태(Cell State)**: LSTM에서 **시점이 바뀌어도 장기 정보를 전달하고 유지하는 내부 상태 정보**. 게이트를 통해 정보를 추가하거나 제거하며, 장기 의존성 학습을 돕는다.
	- **GRU**
		- **업데이트 게이트와 리셋 게이트를 이용**해 **정보를 선택적으로 기억하고 제거**하는 RNN 모델. 
		- **LSTM보다 구조가 단순하고 학습 속도가 빠름**. 별도의 셀 상태 없이 **은닉 상태**만 사용함.
			- **은닉 상태** : 이전 시점의 정보를 반영해 현재 시점에서 유지하고 다음 시점으로 전달하는 정보
		- <mark>**Update Gate, Reset Gate**</mark>
			- **업데이트 게이트(Update Gate)**: 과거 정보와 새로운 정보 중 어떤 정보를 반영할지 결정
			- **리셋 게이트(Reset Gate)**: 과거 정보를 새로운 정보의 계산에 얼마나 반영할지 결정

### 오토인코더
- 입력 데이터를 **인코더로 압축하고, 디코더로 복원하도록 학습하는 비지도 학습 신경망**
- 구조 : **Encoder - Latent Vector(잠재 벡터) - Decoder**
	- **Encoder**: 입력 데이터를 압축해 특징을 추출
	- **Latent Vector**: 압축된 데이터의 특징을 담은 표현
	- **Decoder**: 압축된 표현을 이용해 원본 데이터를 복원
- 활용
	- **차원 축소**: 데이터의 핵심 특징을 저차원으로 표현
	- **이상탐지**: 정상 데이터의 복원 오차를 기준으로 비정상 데이터 탐지
	- **생성 모델**: VAE처럼 구조를 확장해 새로운 데이터 생성
	- 생성모델
		- VAE : 잠재 공간의 **확률분포를 학습**하고, 그 분포에서 샘플링해 새로운 **데이터를 생성**
		- <mark>**GAN<mark><strong> : **생성기와 판별기가 경쟁적으로 학습해 실제 데이터와 유사한 데이터를 생성**(**</mark>적대적 훈련</strong></mark>)
		- DCGAN : **CNN을 GAN에 적용**한 모델로, 이미지 생성에 활용.
- 오토 인코더는 생성형 AI의 기반 모델 -> VAE?
### Seq2Seq
- 인코더와 디코더를 활용하여 한 문장을 다른 문장으로 번역하는 모델
- 입력과 출력의 길이가 달라도 변환이 가능
- 긴 문장에서 정보의 손실이 발생
### 트랜스포머
- 느린 속도와 병렬처리 불가 및 정보 손실의 단점을 개선한 Attention 모델
- Attention : 시퀸스 각 요소에 가중치 부여, 중요 정보에 집중, 장기 의존성 문제 해결
- 구성 요소 : Positional Encoding, Self-Attention, FeedForward Network
- 주요 모델
	- BERT : 구글 개발, 인코더 구조, 문장 중간 빈칸 학습, 양방향
	- GPT : OPEN AI 개발, 디코더 구조, 이전 단어로 다음 단어 예측, 일방향
